The documentation site ships in English plus eight locales, and every
translation is a community contribution. This page explains how to contribute
one or fix an existing one.

## Current Locales

The base language is English. The translated locales are Russian (`ru`),
Simplified Chinese (`zh-Hans`), Japanese (`ja`), Korean (`ko`), Spanish (`es`),
French (`fr`), German (`de`), and Brazilian Portuguese (`pt-BR`).

## Where Translations Live

Each locale mirrors the English tree under `apps/docs/i18n/`:

```
apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/<path>.md
```

UI strings — the navbar, footer, tagline, and sidebar labels — live in JSON
files under `apps/docs/i18n/<locale>/docusaurus-theme-classic/`, generated by
the write-translations command.

## Completeness

Every English page should have a translated counterpart at the same relative
path. Untranslated pages automatically fall back to English, so partial
progress is visible immediately — but aim for full coverage and never submit
half-translated files.

## What to Translate

- Headings, body text, captions, and alt text.
- The front matter `title` and `description`; keep `sidebar_position`
  identical.
- `_category_.json` labels.

## What to Leave Alone

- Links, code fences, inline code, and admonition syntax (`:::note` ... `:::`),
  byte for byte.
- The product name: NeoTavern is never translated.
- API identifiers, file names, commands, and flags stay in their English form.

## Terminology

Use the app's own UI wording where it exists; otherwise use the standard
community term in your language. Where a standard community term already
exists, prefer it — never invent a new word.

## Fixing a Translation

Edit the file for your locale at the same relative path and open a pull
request. When the English source of a page changes, update the translation of
that page in the same change.

## Adding a New Locale

1. Add the locale code and its display label to `i18n.locales` and
   `localeConfigs` in `apps/docs/docusaurus.config.ts`.
2. Scaffold the locale folder:

   ```bash
   pnpm docs:translations -- --locale <code>
   ```

3. Translate every page under
   `apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/` and the
   generated JSON files.
4. Open a pull request containing both the config change and the new files.

Locale codes follow standard conventions, for example `zh-Hans` for Simplified
Chinese and `pt-BR` for Brazilian Portuguese.
