このページでは、グループが何であるかと、NeoTavern が現在複数キャラクターの会話をどう扱うかを説明します。

## グループとは

グループは、複数のキャラクターが参加する 1 つの会話です。通常のチャットが 1 人のキャラクターとあなたのペルソナで構成されるのに対し、グループチャットはキャラクター間を切り替え、各応答を別の参加者から返せるようにします。

## NeoTavern のグループの現状

NeoTavern のコアのチャットモデルは、1 つの会話につき 1 人のキャラクターで、その上にあなたのペルソナが重なります。会話を作成してメンバーをアプリ内で切り替えられる専用のグループチャット機能は**計画中**です。現行リリースでは利用できないため、このページでは代わりに現在動作するものを説明します。

## インポートされたグループチャット

設定 → データ から SillyTavern バックアップを移行すると、グループチャットは安全に処理されます:

- グループ定義とそのトランスクリプトは通常のチャットとしてインポートされ、元のグループレコードがチャットのメタデータに保持されます。
- トランスクリプトはすべての参加者名、メッセージ、スワイプバリアントを保持するため、複数キャラクターの履歴は読みやすく保たれ、会話を継続できます。
- サポートされていないカテゴリは黙って破棄されるのではなく、インポートレポートに明示的に一覧表示されます。

## 複数キャラクターで今すぐできること

ネイティブのグループは計画中ですが、以下の機能で一般的な複数キャラクターのワークフローをカバーできます:

- **キャラクターごとの個別チャット。** 各キャラクターは独自のチャット履歴を持ち、Chats パネルは一覧を現在のキャラクターの範囲に絞り込みます。
- **ロアブックによる共有ワールド。** ロアブックを複数のキャラクターにバインドして、一貫した世界知識をすべての会話に届けます。[ロアブック](lorebook) を参照してください。
- **ストーリーラインのブランチ。** チェックポイントとブランチを使えば、メインの会話を失わずに任意のキャラクターで分岐を探索できます。[チャット](chat) を参照してください。
- **ペルソナ。** チャットごとに自分のペルソナを切り替えて、各会話での自分の見せ方を変えられます。

本当の複数キャラクター会話が必要なら、インポートされたグループチャットの手法を覚えておいてください: 既存のグループ履歴が保持され、計画中のネイティブ機能も同じデータの上に構築されます。
