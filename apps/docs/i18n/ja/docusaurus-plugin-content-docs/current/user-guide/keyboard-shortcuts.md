このページでは、NeoTavern のデフォルトのキーボードショートカットを一覧します。アプリ全体がキーボードで操作でき、すべてのモーダルは閉じるまでフォーカスを自身の内部に保持します。

## コンポーザー

| 操作                         | ショートカット                                             |
| ---------------------------- | ---------------------------------------------------------- |
| メッセージを送信             | `Enter`                                                    |
| 新しい行を挿入               | `Shift+Enter`                                              |
| チャット検索を開く           | チャットヘッダーの検索フィールドにフォーカス               |
| 最新のメッセージへスクロール | 上にスクロールした後に「新しいメッセージ」アクションを使用 |

コンポーザーのヒントは常に現在のモードを表示するため、`Enter` が送信なのか改行なのかを一目で確認できます。

## メッセージの編集

| 操作             | ショートカット                                           |
| ---------------- | -------------------------------------------------------- |
| 編集を保存       | `Ctrl+Enter`（Windows/Linux）または `Cmd+Enter`（macOS） |
| 編集をキャンセル | `Escape`                                                 |

編集は非破壊的です: 以前の内容はメッセージの編集履歴にアーカイブされ、競合時は上書きする代わりに下書きが保持されます。[チャット](chat) を参照してください。

## ナビゲーションとパネル

| 操作                                         | ショートカット                                                    |
| -------------------------------------------- | ----------------------------------------------------------------- |
| 最前面のパネル、ダイアログ、メニューを閉じる | `Escape`                                                          |
| フォーカスを前へ / 後ろへ移動                | `Tab` / `Shift+Tab`                                               |
| ルート対応サーフェスを閉じる                 | ブラウザの戻る                                                    |
| リサイズ可能なパネルをリサイズ               | リサイズハンドルにフォーカスした状態で `ArrowLeft` / `ArrowRight` |
| ナビゲーションメニューを開閉                 | レールのトグルボタン                                              |

`Escape` は最初に最前面のサーフェスを閉じます: ネストされたダイアログは背後のパネルより先に閉じ、フォーカスはそれを開いたコントロールに戻ります。

## チャット操作

| 操作                                   | ショートカット                                                     |
| -------------------------------------- | ------------------------------------------------------------------ |
| スワイプバリアントを切り替える         | `N/M` ページャーの前 / 後の矢印                                    |
| チェックポイントスナップショットを開く | チェックポイントの旗をクリック（`Shift+Click` で新しいものを作成） |
| メッセージを手動で除外または復元       | メッセージバーの除外アクション（手動コンテキスト戦略）             |

メッセージアクションはデスクトップでは常に表示され、モバイルではコンパクトなメッセージカードにグループ化されます。すべてのアクションはフォーカス可能なコントロールなので、ホバーやポインターを必要とするアクションはありません。

## プラグインのホットキー

プラグインは Plugin SDK を通じてホットキーを登録します。SDK が衝突を解決し、最新のアクティブな登録が優先され、プラグインが無効化されるとバインディングが解放されます。プラグインのショートカットがシステムブラウザのコンボを横取りすることはなく、コマンドパレットには各コマンドのショートカットがコンテキスト付きで一覧表示されます。[拡張機能とプラグイン](extensions) を参照してください。
