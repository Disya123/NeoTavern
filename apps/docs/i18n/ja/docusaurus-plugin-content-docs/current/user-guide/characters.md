このページでは、NeoTavern でキャラクターを探す、作成する、編集する、共有する方法を説明します。キャラクターはチャットの参加者であり、AI がそのキャラクターについて知るすべてを格納するキャラクターカードに支えられています。

## キャラクターギャラリー

Characters セクションはライブラリブラウザーです。グリッド表示とコンパクトなリスト表示に対応し、どちらも仮想化されているため、数万枚のカードでも高速に動作します。プレビューにはサムネイルが使われ、元の画像はカードを開いたときだけ読み込まれます。

検索はシンプルなクエリ言語に対応しています: `tag:NSFW author:Name "exact phrase" -tag:beta`。タグと作者のフィルターは検索語と組み合わされ、クエリを入力するたびに関連度順に結果がランク付けされます。並べ替えには、アルファベット順、新しい順、古い順、お気に入り、最近使用した順、チャット数が多い順・少ない順、コンテンツ量が多い順・少ない順、ランダムがあります。

## キャラクターの作成と編集

任意のカードを開いて「編集」を選択します。エディターは明確なグループに分かれています:

- **アイデンティティ** — 名前、アバター、タグ。
- **説明** — キャラクターが誰であるか。
- **最初のメッセージ** — 挨拶と、任意の代替挨拶。
- **シナリオ** — ロールプレイが始まる舞台設定。
- **例** — キャラクターのスタイルを形作る対話例。
- **ロア** — このキャラクターにバインドされたロアブック。
- **画像** — 画像ギャラリー。そのうち 1 枚がプライマリアバターになります。
- **詳細** — 性格、作成者メモ、プロンプトのオーバーライド、深さと役割を持つキャラクターノート、話しやすさ、作成者メタデータ。

キャラクターの作成に必須なのは名前だけです。バリデーションメッセージはフィールドの横と最後のエラー一覧に表示され、必須フィールドは色だけでなくテキストでもラベル付けされます。

## キャラクターカード

キャラクターカードはキャラクターの移植可能な表現です。フィールドには、名前、説明、性格、シナリオ、最初のメッセージ（挨拶）、代替挨拶、タグ、アバターが含まれます。カードには作成者メモも保持され、インポートされたカードの未知のフィールドは破棄されずに保持されるため、別のツールでカードを往復させてもメタデータは失われません。

## カードのインポートとエクスポート

- **インポート** は PNG と JSON のキャラクターカード（V1 と V2）を受け付け、ギャラリー、チャット、初回起動時のセットアップのどこからでも使えます。インポートは繰り返し実行しても安全です — 2 回実行しても重複は作成されません。
- **エクスポート** はカードを PNG または JSON として、あなたが選んだ形式そのままで、現在の状態のバージョンスナップショット付きで書き出します。
- アバターとギャラリー画像はファイルとしてアップロードされ、置き換えた画像は新しい画像が正常に保存されるまで削除されません。

ライブラリ内のカードが破損している場合、NeoTavern は理由付きの安全なプレビューを表示し、元のカードをエクスポートして他の場所で修復できるようにします。
