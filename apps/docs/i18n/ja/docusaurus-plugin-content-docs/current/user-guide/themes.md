このページでは、NeoTavern でテーマがどのように機能するかを説明します: 何を変更できるか、インストールと切り替えの方法、セーフモードがどのようにあなたを守るかです。

## テーマが変更するもの

テーマには 3 つのレベルがあります:

- **デザイントークン** — 色、フォント、間隔、角丸、影、モーションの時間。
- **コンポーネントスキン** — ボタン、パネル、その他のコントロールの見た目。
- **シェルレイアウト** — 名前付き領域の配置: ナビゲーション、キャラクターブラウザー、チャットビューポート、サイドパネル、モーダルレイヤー。

つまりテーマは色の入れ替えではなく、完全なビジュアルオーバーホールです。テーマはチャットロジックを変えずに、ゲームコンソール風、ビジュアルノベル風、モバイルクライアント風にアプリを再スタイリングできます。テーマ、コンポーネントスキン、シェルレイアウトの切り替えに再起動は不要です。

## 同梱テーマ

初回起動時に一連の組み込みテーマが初期化されます。AMOLED、GitHub Dark、Matrix、Nord、Gruvbox、Dracula、Tokyo Night、Catppuccin Mocha などです。テーママネージャーは常にこれらが利用可能な状態で開くため、すぐにスタイルを切り替えられます。

## テーマのインストール

テーマパッケージは `.sttheme` ファイルです — `theme.json` マニフェストと CSS を含む ZIP で、最大 25 MB です。テーママネージャーからインストールします:

1. ナビゲーションレールまたは設定 → テーマ タブからテーマを開きます。
2. パッケージをインストールします。サーバーは何かを書き込む前に、パス、ファイルタイプ、サイズ、マニフェストを検証し、トラバーサルパス、シンボリックリンク、禁止された CSS を拒否します。
3. 適用する前にテーマをプレビューします。プレビューからテーマを受け入れるか、戻るか、設定を開くことができます。
4. 有効化します。インストールだけでテーマが有効化されることはありません。

インストール済みテーマのアップデートはアトミックに置き換えられ、有効化状態が保持されます。テーマの読み込みに失敗した場合、シェルは自動的に最後に動作したレイアウトを復元します。

## カスタムテーマ

テーマはパッケージであり、ハックではありません: テーマはチャット、API キー、ファイルシステムにアクセスできません。Theme SDK は、テーマがスタイリングする安定したフック — `data-component`、`data-part`、`data-role`、`data-state` — と、名前付き領域を定義するシェルコントラクトを文書化しています。カスタム CSS のオーバーライドはカスケードの最後に読み込まれます。独自テーマの作成は[Theme SDK](../developers/theme-sdk/) リファレンスを参照してください。

## セーフモードと復旧

セーフモードはすべてのサードパーティのテーマとプラグインを無効化し、それらが読み込まれる前に到達できるため、壊れたテーマによってロックアウトされることは決してありません。クラッシュループの後、アプリは自動的にセーフ起動を提案します。組み込みの**インターフェースをリセット** アクションは、ファイルを手で編集せずにデフォルトテーマを復元し、どのテーマもそのアクションを隠すことはできません。

アクティブなテーマとメッセージスタイルのオプションがある一般タブについては[設定](settings) を参照してください。
