このガイドでは、NeoTavern を日常的に使ううえでのすべてを扱います: キャラクターとのチャット、ライブラリの構築、生成の調整、データの保護です。各ページは自己完結しているので、どこから始めてもかまいません。

## ガイドの構成

ユーザーガイドはアプリ自体の形に従っています。NeoTavern はチャットファーストの単一ワークスペースを維持します: チャットキャンバスがメイン画面で、それ以外のすべて — キャラクター、チャット、ロアブック、プロバイダー、テーマ、プラグイン、設定 — はその上にパネルやモーダルとして開きます。パネルを閉じると、離れたときのチャット、スクロール位置、下書きがそのまま復元されるため、以下のどのページも会話を離れることを前提にしていません。

各ページは緩やかな順序で互いに積み重なっています:

## セクション

- [チャット](user-guide/chat) — メッセージの送信、ストリーミング応答、スワイプ（代替応答）、再生成、編集、停止、メッセージスナップショット。コアの操作を理解したいならここから始めてください。
- [キャラクター](user-guide/characters) — 検索とフィルターを備えたキャラクターギャラリー、キャラクターカードのフィールド、PNG または JSON としてのカードのインポート・エクスポート。
- [グループ](user-guide/groups) — 複数キャラクターの会話: 現在できること、SillyTavern のグループチャットがマイグレーションでどう届くか、何が計画されているか。
- [ロアブック](user-guide/lorebook) — 起動キーワードが一致したときにプロンプトに注入される世界知識、エントリ設定、挿入順序、キャラクターへのバインド。
- [メモリとリコール](user-guide/memory) — ローリング会話メモリ、キーワード起動のメモリエントリ、ベクターリコール、RAG。
- [設定](user-guide/settings) — グローバル設定とチャットごとの設定の場所、接続プロファイル、プロバイダー、ローカル API キーマネージャー。
- [テーマ](user-guide/themes) — 同梱テーマとカスタムテーマ、3 つのテーマレベル、インストールと切り替え、セーフモード。
- [拡張機能とプラグイン](user-guide/extensions) — プラグインのインストール、権限と同意フロー、管理とアンインストール、プラグインの安全性。
- [データとバックアップ](user-guide/data-and-backups) — データディレクトリの構成、エクスポートとインポート、SillyTavern マイグレーション、バックアップの作成と復元。
- [キーボードショートカット](user-guide/keyboard-shortcuts) — コンポーザー、編集、ナビゲーション、チャット操作のデフォルトショートカットを 1 つの表で。

## 始める前に

アプリをまだインストールしていない場合は、[インストール](getting-started/installation) から始めてください。クリーンインストールから最初のメッセージまでは[クイックスタート](getting-started/quick-start) に従ってください。問題が発生した場合は[トラブルシューティング](getting-started/troubleshooting) を確認し、よくある質問への簡単な回答は[FAQ](faq) を参照してください。
