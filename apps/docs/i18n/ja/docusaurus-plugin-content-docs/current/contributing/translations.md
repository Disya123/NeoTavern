ドキュメントサイトは英語と 8 つのロケールで公開され、すべての翻訳はコミュニティの貢献です。このページでは、翻訳の貢献方法または既存の翻訳の修正方法を説明します。

## 現在のロケール

ベース言語は英語です。翻訳されたロケールは、ロシア語（`ru`）、簡体字中国語（`zh-Hans`）、日本語（`ja`）、韓国語（`ko`）、スペイン語（`es`）、フランス語（`fr`）、ドイツ語（`de`）、ブラジルポルトガル語（`pt-BR`）です。

## 翻訳が置かれる場所

各ロケールは `apps/docs/i18n/` の下で英語ツリーをミラーします:

```
apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/<path>.md
```

UI 文字列 — ナビゲーションバー、フッター、タグライン、サイドバーラベル — は `apps/docs/i18n/<locale>/docusaurus-theme-classic/` の下の JSON ファイルにあり、write-translations コマンドで生成されます。

## 完全性

すべての英語ページには、同じ相対パスに翻訳された対応物があるべきです。未翻訳のページは自動的に英語にフォールバックするため、部分的な進捗はすぐに見えます — ただし完全なカバレッジを目指し、半分翻訳されたファイルを提出しないでください。

## 翻訳するもの

- 見出し、本文、キャプション、代替テキスト。
- フロントマターの `title` と `description`。`sidebar_position` は同一に保ちます。
- `_category_.json` のラベル。

## そのままにしておくもの

- リンク、コードフェンス、インラインコード、アドモニション構文（`:::note` ... `:::`）をバイト単位で。
- 製品名: NeoTavern は翻訳されません。
- API 識別子、ファイル名、コマンド、フラグは英語の形式のままです。

## 用語

アプリ自身の UI 表現が存在する場合はそれを使用し、それ以外の場合は言語の標準的なコミュニティ用語を使用してください。標準的なコミュニティ用語がすでに存在する場合はそれを優先し、新しい単語を発明しないでください。

## 翻訳の修正

ロケールのファイルを同じ相対パスで編集し、プルリクエストを開いてください。ページの英語ソースが変更されたら、同じ変更でそのページの翻訳も更新してください。

## 新しいロケールの追加

1. ロケールコードと表示ラベルを `apps/docs/docusaurus.config.ts` の `i18n.locales` と `localeConfigs` に追加します。
2. ロケールフォルダをスキャフォールドします:

   ```bash
   pnpm docs:translations -- --locale <code>
   ```

3. `apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/` の下のすべてのページと、生成された JSON ファイルを翻訳します。
4. 設定変更と新しいファイルの両方を含むプルリクエストを開いてください。

ロケールコードは標準的な慣例に従います。例: 簡体字中国語は `zh-Hans`、ブラジルポルトガル語は `pt-BR`。
