このページでは、NeoTavern についてユーザーから最もよく寄せられる質問に回答します。

## データはどこに保存されますか？

チャット、キャラクター、ペルソナ、グループ、ロアブック、メモリ、設定など、すべてのデータはあなたのマシン上のデータディレクトリに保存されます。このディレクトリには SQLite データベースと、キャラクターカード、画像、その他のアセットを保持するファイルストアが含まれます。正確な構成と移行方法については、[データとストレージ](./developers/data/) と [データとバックアップ](./user-guide/data-and-backups) を参照してください。

## NeoTavern はオフラインで使えますか？

はい。NeoTavern はローカルファーストでオフライン対応です。ローカルモデルのエンドポイントを指定すれば、インターネット接続なしでチャットできます。クラウドプロバイダーは当然ネットワークが必要で、接続がない場合はアプリがその旨を通知します。

## データはクラウドに送信されますか？

いいえ。チャットとファイルはあなたのマシン上に残ります。ネットワークトラフィックは、あなたが明示的に設定したリクエスト（生成、音声、画像のために接続するプロバイダーへのリクエスト）だけです。アプリはデフォルトではテレメトリを送信しません。

## API キーは必要ですか？

接続するクラウドプロバイダーについてのみ必要です。ローカルモデルにはキーは一切不要です。各プロバイダーは設定画面で構成し、キーは接続プロファイルに保持されます。

## プラグインは安全ですか？

プラグインは権限モデルの下で実行され、サンドボックス化されています。バックエンドプラグインは制限されたプロセスで実行され、プラグイン UI はメインアプリから分離されます。インストール時に権限を付与し、問題が発生した場合のセーフモードではプラグインとテーマなしでアプリを起動できます。[拡張機能](./user-guide/extensions) と [プラグイン SDK](./developers/plugin-sdk/) を参照してください。

## 既存のキャラクターを使えますか？

はい。NeoTavern は標準のキャラクターカードをインポートできます。JSON を埋め込んだ PNG カードにも対応しているため、他のチャットアプリやコミュニティのキャラクターギャラリーのキャラクターがそのまま使えます。[キャラクター](./user-guide/characters) を参照してください。

## SillyTavern 時代のプラグインを移行できますか？

古い SillyTavern 環境向けに書かれたプラグインは、レガシー互換レイヤーを通じて実行できます。このレイヤーはおなじみの `window.SillyTavern`、`window.eventSource`、`window.$` グローバルと Express 互換の HTTP ホストを提供します。これは互換のための経路であり、書き直しの対象ではありません。新しいプラグインは[プラグイン SDK](./developers/plugin-sdk/) を使用してください。[レガシー互換](./developers/legacy-compat) を参照してください。

## アップデートはどのように行われますか？

アップデートはその場でインストールされ、データディレクトリは保持されます。変更履歴には各リリースの変更点が記載されています。アップデート前に読んで、破壊的変更を把握してください。

## システム要件は何ですか？

NeoTavern は Windows（インストーラーまたはポータブルビルド）、macOS（パッケージ）、Linux（AppImage またはアーカイブ）で動作します。デスクトップアプリには Node.js ランタイムが同梱されているため、追加のインストールは不要です。64 ビットの現行 OS と、バックエンド用に数百 MB 程度の空き RAM があれば、一般的な利用には十分です。

## Web 版やモバイル版はありますか？

デスクトップアプリは Tauri で構築され、PWA コンパニオンが付属しています。Web UI はオフラインのアプリシェルを持つプログレッシブウェブアプリとしてインストールできます。[デスクトップ](./developers/desktop/) を参照してください。

## データをバックアップするにはどうすればいいですか？

チャットをファイルにエクスポートするか、ライブラリ全体をエクスポートするか、アプリを停止した状態でデータディレクトリをコピーしてください。バックアップはプレーンで移植性のあるファイルです。インポートまたは元の場所への復元でリストアできます。[データとバックアップ](./user-guide/data-and-backups) と [バックアップ](./developers/data/backups) を参照してください。

## セーフモードとは何ですか？

セーフモードは、プラグインとテーマなしで NeoTavern を起動するため、サードパーティのコードが原因の問題を診断できます。プラグインやテーマをインストールした後にアプリが起動しない場合は、セーフモードを使用してください。[トラブルシューティング](./getting-started/troubleshooting) を参照してください。

## バグの報告や機能のリクエストはどうすればいいですか？

[GitHub リポジトリ](https://github.com/Disya123/NeoTavern) でバージョン、OS、再現手順を添えて issue を開いてください。機能リクエストも歓迎します。

## 変更履歴はどこにありますか？

変更履歴はリポジトリ内の [CHANGELOG.md](https://github.com/Disya123/NeoTavern/blob/main/CHANGELOG.md) にあります。
