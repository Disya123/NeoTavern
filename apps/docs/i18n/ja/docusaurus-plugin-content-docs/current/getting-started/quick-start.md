このページでは、クリーンインストールから最初の生成メッセージまでを約 5 分で案内します。必要なのはアクティブなプロバイダーだけです。それ以外はすべて任意です。

## 1. アプリを起動する

NeoTavern を開きます。ホーム画面が直接開き、初回起動時には言語と文字サイズを選ぶ非ブロッキングのチェックリストが表示されます。チェックリストは無視して後で戻ることもできます — キャラクターギャラリー、インポート、ローカル設定をブロックするものはありません。

## 2. プロバイダーを接続する

生成にはプロバイダーが必要です: マシン上のローカルモデルサーバーか、リモート API です。AI 設定パネルまたは Providers セクションを開きます:

1. API タイプ（例: Chat Completions）と、プロバイダーを定義するソースを選択します。
2. API キーを入力します。キーはローカルに保存され、保存後に完全な形で表示されることはなく、デフォルトではエクスポートにも含まれません。
3. 任意でそのプロバイダーのモデル一覧を読み込んでモデルを選択します。
4. **接続テスト** で可用性とレイテンシを確認し、**接続** でプロファイルを有効化します。

プロバイダーがまだない場合: 組み込みの **Echo** プロバイダーを選べば、オフラインでパイプライン全体をテストできます。Echo は定型のエコーを返すだけで、キーもネットワークアクセスも不要です。

アクティブなプロバイダーがない間は送信ボタンが無効になり、その理由が隣に表示されます。プロバイダーのエラーでローカルライブラリにアクセスできなくなることはありません。

## 3. キャラクターを選ぶか作成する

ナビゲーションレールから Characters セクションを開きます:

- ギャラリーを閲覧してカードを開き、チャットを開始します。
- ディスクからキャラクターカード（PNG または JSON）をインポートします。
- ゼロから新しいキャラクターを作成します — 名前だけで十分です。

詳細は[キャラクター](../user-guide/characters) を参照してください。

## 4. 最初のメッセージを送信する

キャラクターを選択すると、チャットキャンバスが開き、キャラクターの挨拶が最初のアシスタントメッセージとして表示されます。下に入力して `Enter` で送信します。チャットは最初の空でないメッセージを送信した後にのみバックエンドに作成されるため、閲覧だけでは空のチャットが残りません。

応答は生成されながらストリーミング表示されます。いつでも停止でき、ストリーミング中でも履歴をスクロールして遡れます。チャットビューでできることのすべては[チャット](../user-guide/chat) を参照してください。
