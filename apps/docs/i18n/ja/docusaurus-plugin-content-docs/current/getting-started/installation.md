このページでは、Windows、macOS、Linux に NeoTavern をインストールする方法を説明します。ご利用のプラットフォーム向けのビルドは [GitHub リリースページ](https://github.com/Disya123/NeoTavern/releases) からダウンロードしてください。

## インストール対象

- **Windows インストーラー。** アプリをインストールしてショートカットを追加するセットアップ実行ファイル。ほとんどの Windows ユーザーに推奨します。
- **Windows ポータブルビルド。** インストールなしで動作する自己完結型フォルダ。すべてのデータを自身のディレクトリ内に保持するため、USB ドライブに入れて持ち運べます。
- **macOS パッケージ。** 標準の `.app` バンドル。Applications にドラッグしてそこから起動します。
- **Linux AppImage とアーカイブ。** AppImage はほとんどのデスクトップディストリビューションで動作します。アーカイブ版はプレーンなフォルダで、どこにでも置いてダブルクリックで起動できます。

4 つの対象は機能的にすべて同一です。お使いのマシンでのソフトウェア管理方法に合わせて選んでください。

## システム要件

- 64 ビットのデスクトップ OS: Windows 10 以降、macOS、または主流の Linux ディストリビューション。
- ライブラリを収容するのに十分なメモリとディスク容量。アイドル時のバックエンドは基準マシンで約 180 MB の RAM を使用し、同じマシンで約 4 秒で UI の準備が整います。
- Node.js、Python、SQLite、ブラウザの個別インストールは不要です。アプリに必要なものはすべて同梱されています。

## 同梱されているもの

ディストリビューションには Node.js 24 LTS と SQLite が組み込まれており、デスクトップシェルはローカルバックエンドを組み込みサイドカープロセスとして実行します。つまり:

- 初回起動で `npm install` が実行されることはなく、ターミナルも必要ありません。
- バックエンドは `127.0.0.1` のみにバインドします。LAN やリモートアクセスが黙って有効になることはなく、明示的なオプトインが必要です。
- アプリのウィンドウを閉じるとサイドカーは正常にシャットダウンするため、バックエンドプロセスが残ることはありません。

## インストール後

初回起動時にデータディレクトリが作成され、スターターライブラリが初期化されて、ホーム画面が開きます。次の手順は[クイックスタート](quick-start) を参照してください。

インストール中または初回起動時に問題が発生した場合は、[トラブルシューティング](troubleshooting) を参照してください。
