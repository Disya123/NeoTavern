NeoTavern は、あなた自身のコンピュータ上で動作するローカルファーストの AI チャット・ロールプレイプラットフォームです。キャラクターを作成またはインポートし、接続した任意の AI モデルと会話し、すべてのメッセージ、キャラクターカード、設定をマシン上に保持します。

## ローカルファーストの設計

- データはコンピュータ上のローカルなデータディレクトリに保存されます。アカウントも、必須のクラウド同期も、デフォルトのテレメトリもありません。
- オフラインでもライブラリの閲覧、キャラクターの編集、設定の確認ができます。外部 AI サービスへのアクセスが必要なのは生成だけです。
- 外部 AI サービスにデータを初めて送信する前に、どのプロバイダーがリクエストを受け取るかがアプリに正確に表示されます。

## 動作の仕組み

- デスクトップアプリは Windows、macOS、Linux で利用できます。Node.js と SQLite が同梱されているため、ランタイムを自分でインストールする必要はありません。
- アプリは独自のローカルバックエンド、つまりデフォルトで `127.0.0.1:8000` をリッスンし、ウィンドウとともに終了する組み込みの Node.js サイドカーを起動します。
- レスポンシブな PWA により、スマートフォンやタブレットから PC やホームサーバーで動作するバックエンドに接続できます。

## 必要なもの

- 対応する 64 ビットのデスクトップ OS。ターミナル、Git、パッケージマネージャーは一切不要です。
- 応答を生成するプロバイダー: ローカルモデルサーバーか、自分のキーを使うリモート API。組み込みの Echo プロバイダーを使えば、外部サービスなしでオフラインのまま全体のフローを検証できます。
- 任意ですが便利なもの: キャラクター、チャット、ロアブック、ペルソナを移行するための既存の SillyTavern データバックアップ。
