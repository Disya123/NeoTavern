NeoTavern はローカルファーストの AI チャット・ロールプレイプラットフォームです。チャット、キャラクター、ロアブック、ペルソナ、設定はすべてあなたのマシン上に保存され、それらを動かすプロバイダーも自分で選べます。

## すべてはあなたのマシン上に

- **ローカルファーストの保存。** チャット、キャラクター、グループ、ロアブック、メモリ、設定はデータディレクトリに保存され、プレーンなファイルとしてエクスポートできます。
- **オフライン対応。** ローカルモデルを使えばネットワーク接続なしでもチャットを続けられます。回線が途切れても作業を続行できます。
- **プロバイダーの自由。** 独自の LLM、音声合成、音声認識、画像生成プロバイダーを接続できます。自分の API キーを使うもよし、キーなしで使うもよしです。
- **プラグインエコシステム。** パネル、ツールバーアクション、スラッシュコマンド、プロンプトインターセプターなどで NeoTavern を拡張できます。権限モデルとサンドボックスで保護されています。
- **テーマ。** Theme SDK のデザイントークン、スキン、レイアウトでアプリ全体を再スタイリングできます。
