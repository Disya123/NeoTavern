NeoTavern 代码贡献遵循一组共享规则：严格 TypeScript、明确的错误契约、
文档作为变更的一部分，以及可衡量的性能目标。

## TypeScript

- 所有代码都启用严格模式；保持开启。
- 无正当理由的 `any`、`@ts-ignore`、非空断言和 `as unknown as` 转换被禁止。
- 在系统边界 —— 解析、请求、文件、插件输入 —— 使用 `unknown`，
  并在信任数据之前显式校验。
- 公共接口暴露导出的类型。绝不要手工重复后端和前端类型：共享 API 类型
  位于 `packages/contracts`，从那里导入。
- 全程使用 ESM。
- 偏好带显式输入和输出的小函数，而不是大型有状态的函数。

## API 错误

每个 API 错误都使用稳定、机器可读的信封：

```json
{
  "code": "CHARACTER_NOT_FOUND",
  "params": { "characterId": "0193..." },
  "traceId": "01J4..."
}
```

- `code` 是一个稳定、机器可读的错误标识符 —— 一旦发布就不要更改。
- `params` 携带客户端或插件可以操作的上下文。
- `traceId` 把错误与服务器日志关联起来。
- 面向用户的文本绝不在后端拼装：前端把 code 和 params 本地化为界面文本。

## 文档是实现的一部分

文档是实现的一部分，而不是代码之后的尾巴。任何影响用户或开发者行为的
变更都要在同一个变更中更新 `docs/` 中的相关文件。以下内容必须如此：

- 架构和包边界；
- REST API、SSE、WebSocket 和契约 schema；
- 插件 SDK、主题 SDK 和旧版兼容层；
- 权限、沙箱化和安全模型；
- SQLite schema、迁移、备份和恢复；
- 导入、导出、文件和缩略图缓存；
- 提示词管线、instruct 格式、分词和上下文移位；
- 提供商适配器；
- 桌面打包、Tauri sidecar、PWA 和更新；
- 用户设置、i18n 和无障碍；
- 破坏性变更、弃用和迁移指南。

附加规则：

- 每个新的 `app` 或 `package` 都附带一个 `README.md`，
  涵盖用途、公共入口点、依赖、开发命令和约束。
- 当名称本身无法解释契约时，公共 TypeScript 导出和 SDK 扩展点获得 TSDoc。
- 用户可见的变更被添加到 `CHANGELOG.md`；破坏性变更还要有迁移指南。
- 不要把未实现的功能文档化为就绪 —— 把它们标记为"实验性"或"计划中"。
- 每个契约保持一个事实来源并链接到它；不要把同一个契约复制到多个地方。

## i18n

- UI 代码中没有硬编码的面向用户字符串。所有字符串都经过 i18next
  命名空间。
- 用 `Intl` 格式化复数、日期、数字和单位，而不是字符串拼接。
- 语言切换无需页面重新加载；更新 `<html>` 上的 `lang` 和 `dir`。
- 支持 RTL 布局。
- 插件和主题使用隔离的命名空间，因此它们不会与应用冲突。
- 后端返回错误码；前端本地化它们。
- 为新界面添加伪语言环境检查，并验证长翻译下的界面。

## 性能目标

未经明确决定，不要使这些目标回退：

| 目标                               | 预算       |
| ---------------------------------- | ---------- |
| 启动到就绪界面（参考 PC）          | 4 秒       |
| 后端空闲内存                       | 180 MB     |
| 10 万个角色的首页                  | 300 毫秒   |
| 打开 10,000 条消息的聊天到最新消息 | 700 毫秒   |
| 流式 UI 更新                       | 每秒 30 次 |
| 初始前端包（gzip，惰性分块之前）   | 2 MB       |

在优化前后都要测量。不要在没有失效策略的情况下添加缓存。

## 测试

每个变更都在适当的层级添加测试：Vitest 单元测试、Fastify `inject()`
集成测试、Playwright 端到端测试、主题和外壳布局的视觉回归测试、无障碍
测试、迁移测试、插件契约测试和旧版兼容套件。覆盖错误和损坏输入、请求
取消、重新导入、迁移和回滚、备份恢复、缓存清理、插件禁用、安全模式、
大型目录和长聊天、令牌预算边界处的上下文移位、instruct 格式渲染，
以及缩略图生成和失效。

## 完成定义

推送之前：`pnpm format`、零警告的 `pnpm lint`、`pnpm typecheck`、
`pnpm test`，UI 变更还要 `pnpm test:e2e`。确认相关文档、示例和迁移指南
已更新，且文档链接可以解析。
