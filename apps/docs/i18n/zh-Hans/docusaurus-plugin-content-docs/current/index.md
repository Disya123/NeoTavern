NeoTavern 是一个本地优先的 AI 聊天与角色扮演平台：你的聊天记录、角色、
设定集、人设和设置都保存在你自己的机器上，由你选择驱动它们的提供商。

## 一切都在你的机器上

- **本地优先存储。** 聊天记录、角色、群组、设定集、记忆和设置都存放在
  你的数据目录中，并且可以导出为普通文件。
- **支持离线使用。** 使用本地模型时，即使没有网络连接也能继续聊天，
  网络断开时也能照常工作。
- **提供商自由。** 连接你自己的大语言模型、文本转语音、语音转文本和图像
  提供商 —— 使用你自己的 API 密钥，或者完全不使用。
- **插件生态。** 通过插件扩展 NeoTavern：面板、工具栏操作、斜杠命令和
  提示词拦截器，并受到权限与沙箱模型的保护。
- **主题。** 使用主题 SDK 提供的设计令牌、皮肤和布局，为整个应用换上新外观。
