本指南涵盖你在 NeoTavern 中每天要做的一切：与角色聊天、构建你的资料库、
调整生成参数、保护你的数据安全。每个页面都自包含，因此你可以从任何
地方开始。

## 指南的组织方式

用户指南遵循应用本身的形态。NeoTavern 保持一个单一的聊天优先工作区：
聊天画布是主屏幕，其他一切 —— 角色、聊天记录、设定集、提供商、主题、
插件和设置 —— 都以面板或模态框的形式叠加在它之上。关闭面板会返回你
离开时的那条聊天、滚动位置和草稿，因此下面的任何页面都不假设你会离开
对话。

各页面之间以松散的顺序相互衔接：

## 章节

- [聊天](user-guide/chat) —— 发送消息、流式回复、滑动（备选回复）、重新生成、编辑、
  停止和消息快照。想理解核心交互的话，从这里开始。
- [角色](user-guide/characters) —— 带搜索和筛选的角色画廊、角色卡字段，以及以 PNG
  或 JSON 格式导入或导出卡片。
- [群组](user-guide/groups) —— 多角色对话：目前已有的功能、SillyTavern 群组聊天
  如何通过迁移到达，以及计划中的内容。
- [设定集](user-guide/lorebook) —— 当激活关键词匹配时注入提示词的世界知识、
  条目设置、插入顺序，以及将书绑定到角色。
- [记忆与召回](user-guide/memory) —— 滚动式对话记忆、关键词激活的记忆条目、
  向量召回和 RAG。
- [设置](user-guide/settings) —— 全局和每聊天设置的位置、连接配置文件、提供商和
  本地 API 密钥管理器。
- [主题](user-guide/themes) —— 内置和自定义主题、三个主题层级、安装与切换，
  以及安全模式。
- [扩展与插件](user-guide/extensions) —— 安装插件、权限与同意流程、管理和卸载，
  以及插件安全。
- [数据与备份](user-guide/data-and-backups) —— 数据目录布局、导出和导入、
  SillyTavern 迁移，以及创建和恢复备份。
- [键盘快捷键](user-guide/keyboard-shortcuts) —— 编辑器、编辑、导航和聊天操作的
  默认快捷键一览表。
