本页说明 NeoTavern 中的设置位于何处，以及如何配置提供商、连接配置文件
和 API 密钥。

## 设置在哪里

NeoTavern 没有单独的设置页面。一切都以面板或模态框的形式在聊天工作区
之上打开，关闭后会返回完全相同的聊天和草稿：

- **设置**（从导航栏进入）把应用级选项分组到选项卡中：**常规**（语言、
  文字大小、启动屏幕、消息样式、头像形状、无障碍）、**主题**（安装和激活
  主题）和**数据**（迁移、备份、缓存维护、诊断）。
- **AI 设置**是生成参数的上下文面板。其**配置**选项卡保存活动模型的请求
  参数：上下文大小、响应长度、流式输出、采样、惩罚、种子和推理。
  **API** 选项卡管理连接配置文件和密钥，**高级**从 ChatML、Llama 3 或
  Alpaca 构建自定义聊天和指令模板。

设置更改在容易撤销的地方立即生效。与默认值不同的选项会被标记出来，
并且可以单独重置；设置搜索覆盖名称、描述和关键词。

## 全局与每聊天设置

**设置**中的全局设置适用于整个应用：语言、主题、数据管理和默认值。
每聊天行为紧挨着聊天存在：生成参数、活动的提供商和模型以及上下文策略
在 AI 设置面板中编辑，聊天保持打开，草稿和滚动位置被保留。人设也是
每聊天的 —— 每个对话可以使用不同的人设，而应用级的活动人设仍然是默认值。

## 提供商和连接配置文件

连接配置文件捆绑了与提供商通信所需的一切：API 类型和来源、适用的基础
URL、所选 API 密钥和模型。AI 设置中的 **API** 选项卡（以及"提供商"部分）
让你可以：

1. 选择顶层 API（Chat Completions 或 Text Completions）。
2. 选择一个来源，它会筛选出该 API 的来源，并成为配置文件名称。
3. 输入 OpenAI 兼容服务器的基础 URL，通常以 `/v1` 结尾。
4. 选择或输入模型 ID，也可以先加载模型列表。
5. **测试连接**以检查可用性和延迟，然后**连接**以激活配置文件。

## API 密钥

密钥存储在本地的一个密钥管理器中，每个提供商可保存多个命名密钥，
同时激活一个。密钥在保存前会经过验证，之后绝不会完整显示 ——
只保留一个掩码后缀可见。导出和诊断默认排除密钥，提供商错误会以本地化
消息显示，并在可折叠块中提供技术细节和 trace ID。

应用级设置的其他部分请参阅[主题](themes)、[扩展](extensions)和
[数据与备份](data-and-backups)。
