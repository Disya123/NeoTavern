本页说明如何在 NeoTavern 中查找、创建、编辑和分享角色。角色是你聊天中的
参与者，由一张角色卡支撑，卡片存储着 AI 所知道的关于该角色的一切。

## 角色画廊

"角色"部分是你的资料库浏览器。它支持网格视图和紧凑列表视图，两者都经过
虚拟化，因此即使有数万张卡片也能保持流畅。预览使用缩略图；原始图像只在
你打开卡片时加载。

搜索支持简单的查询语法：`tag:NSFW author:Name "exact phrase" -tag:beta`。
标签和作者筛选会与搜索词组合，输入查询时结果会按相关性排序。排序方式包括
字母顺序、最新、最旧、收藏、最近使用、聊天多或少、内容多或少以及随机。

## 创建和编辑角色

打开任意卡片并选择"编辑"。编辑器分为清晰的几个组：

- **身份** —— 名称、头像和标签。
- **描述** —— 角色是谁。
- **第一条消息** —— 开场白，以及备选开场白。
- **场景** —— 角色扮演开始的设定。
- **示例** —— 塑造角色风格的对话示例。
- **设定** —— 绑定到该角色的设定集。
- **图像** —— 图像画廊，其中一张是主头像。
- **高级** —— 性格、创作者备注、提示词覆盖、带深度和角色的角色备注、
  话痨程度和创作者元数据。

创建角色只需要名称。校验消息会显示在字段旁边以及最终的错误列表中，
必填字段用文字标注，而不仅仅是颜色。

## 角色卡

角色卡是角色的可移植表示。其字段包括名称、描述、性格、场景、第一条消息
（开场白）、备选开场白、标签和头像。卡片还带有创作者备注，导入卡片中的
未知字段会被保留而不是丢弃，因此当你把卡片通过其他工具往返传输时，
不会有元数据丢失。

## 导入和导出卡片

- **导入**接受 PNG 和 JSON 角色卡（V1 和 V2），可以从画廊、从聊天中，
  或在首次运行设置期间进行。导入可以安全地重复执行 —— 运行两次绝不会
  产生重复。
- **导出**会按照你的选择把卡片写成 PNG 或 JSON，并带有当前状态的版本快照。
- 头像和画廊图像作为文件上传；被替换的图像只有在新图像保存成功后才被移除。

如果你的资料库中有一张卡片损坏了，NeoTavern 会显示带原因的安全预览，
并允许你导出原始文件，以便在其他地方修复它。
