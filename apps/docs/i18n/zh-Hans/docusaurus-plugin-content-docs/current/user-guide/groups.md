本页说明什么是群组，以及 NeoTavern 目前如何处理多角色对话。

## 什么是群组

群组是多个角色参与的单一对话。普通聊天是一个角色加上你的人设，
而群组聊天会在角色之间切换，因此每条回复都可以来自不同的参与者。

## NeoTavern 目前的群组

NeoTavern 的核心聊天模型是每个对话一个角色，人设叠加在其上。一个专门的
群组聊天功能 —— 让你创建对话并在应用内切换成员 —— 目前**计划中**；
它还没有在当前版本中提供，因此本页描述的是目前可用的功能。

## 导入的群组聊天

当你通过设置 → 数据迁移 SillyTavern 备份时，群组聊天会被安全地处理：

- 群组定义及其记录会被导入为普通聊天，并在聊天元数据中携带原始群组记录。
- 记录保留每个参与者的名字、消息和滑动变体，因此多角色历史仍然可读，
  你可以继续这个对话。
- 不支持的类别会在导入报告中明确列出，而不是被静默丢弃。

## 现在使用多个角色

虽然原生群组还在计划中，以下功能覆盖了常见的多角色工作流：

- **每个角色一个聊天。** 每个角色保留自己的聊天历史，"聊天"面板会把列表
  限定到当前角色。
- **通过设定集共享世界。** 把一个设定集绑定到多个角色，让一致的世界知识
  到达每个对话。请参阅[设定集](lorebook)。
- **剧情线分支。** 使用检查点和分支，在保留主对话的同时与任何角色探索
  分叉路径。请参阅[聊天](chat)。
- **人设。** 为每个聊天切换你的人设，改变你在每个对话中的呈现方式。

如果你需要真正的多角色对话，请记住导入的群组聊天方案：它保留你现有的
群组历史，计划中的原生功能将建立在同样的数据之上。
