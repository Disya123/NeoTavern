本页说明设定集：NeoTavern 在内容变得相关的那一刻将其注入提示词的世界知识集合。

## 什么是设定集

设定集是一组关于某个世界、背景或角色的条目：地点、派系、历史、人物、
魔法规则 —— 任何模型应该知道、但如果每条消息都包含会浪费令牌的内容。
应用不会把整本书加载进提示词，而只激活关键词与当前对话匹配的条目。

一本书的作用域要么是**全局**（在每个聊天中都可用），要么绑定到一个
**角色**（只在该角色的对话中使用）。你可以在角色编辑器的"设定"部分按角色
链接和取消链接书。

## 条目

每个条目都有：

- **主关键词** —— 一个或多个激活关键词。至少需要一个主关键词。
- **次关键词** —— 额外的可选关键词。
- **内容** —— 条目触发时注入提示词的文本。
- **位置** —— 条目相对于其他条目的插入位置。
- **开关** —— `enabled`（参与激活）、`constant`（始终包含）和 `selective`
  （只在配置的位置插入）。

匹配是对对话上下文进行不区分大小写的子字符串匹配。条目触发时，其内容会
插入到提示词中该条目的位置，条目对话框会显示其大小的令牌估算，
以便你保持预算可预测。

## 插入顺序

管线按固定顺序组装提示词块：主提示词、角色前设定集、人设、角色、
角色后设定集、对话示例、记忆、聊天历史、历史后指令，以及当前用户输入。
设定集条目与记忆块一起按相关性排序，常量条目始终存在。已激活条目的实际
顺序遵循它们在书中的位置，因此结构良好的书会产生稳定的提示词。

## 管理书

导航栏中的"设定集"面板有三个选项卡：书列表、书编辑器和条目列表。
列表显示每本书的名称、描述、加载次数和作用域徽章（全局或角色），
并提供全局书、特定角色的书或全部书的筛选。书删除后进入回收站状态并可恢复，
对大型资料库的搜索会进行防抖处理。

从角色编辑器新建的书会立即绑定到该角色。编辑器请参阅[角色](characters)，
记忆块与设定集条目如何交互请参阅[记忆与召回](memory)。
