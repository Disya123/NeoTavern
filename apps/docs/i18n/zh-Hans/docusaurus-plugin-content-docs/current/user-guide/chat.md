本页介绍聊天视图：编写和发送消息、观看回复流式显示，以及使用 NeoTavern
提供的消息操作。

## 发送消息

输入框位于聊天画布底部。输入消息并按 `Enter` 发送；按 `Shift+Enter`
换行。你的消息会立即出现，回复会以每秒最多 30 次界面更新的批量方式
流式显示到视图中。回复流式输出时你可以滚动浏览历史 —— 只有停留在底部时
自动滚动才会跟随你，手动向上滚动后会出现"新消息"操作。

回复生成期间，输入框的主按钮会变成**停止**。停止会保留到目前为止收到的
文本，并将其明确标记为不完整回复。连接断开时提供重新连接选项，
绝不会创建重复消息。

你的草稿按聊天分别保存，因此切换离开再回来也不会丢失正在输入的内容。

## 滑动（备选回复）

每条助手消息都可以保存多个备选回复，称为滑动。消息下方的分页器以 `N/M`
形式显示数量，并带有上一个/下一个箭头；点击箭头可以在各个变体之间循环，
不会丢失任何一个。滑动历史会被保留，且是非破坏性的。

## 重新生成

重新生成操作会就地重写**最新**的助手消息：新回复会流式显示到现有的气泡中，
之前的文本成为滑动分页器中的另一个变体。如果生成失败或被停止，
旧文本会原样保留在磁盘上。

## 编辑消息

在消息上打开编辑操作即可修改其文本。内联编辑器使用 `Ctrl+Enter`
（macOS 上为 `Cmd+Enter`）保存，使用 `Escape` 取消。编辑是非破坏性的：
之前的内容会归档到消息的编辑历史中，你可以随时从中恢复。如果在你编辑期间
消息在别处发生了变化，编辑器会保留你的草稿并显示冲突提示，
而不是静默覆盖。

## 消息操作

每条消息上的操作栏始终可见，而不是仅在悬停时显示：

- 复制原始消息文本。
- 编辑消息。
- 重新生成最后的助手回复。
- 在变体之间滑动。
- 创建**检查点**或**分支**：在该消息处冻结的聊天快照，复制到一个子聊天中。
  使用检查点来探索剧情线，而不影响主对话。
- 删除消息。删除会把聊天移入回收站状态，而不是立即销毁。

插件可以在同一操作栏中添加自己的操作，前提是你授予了相应的权限。
请参阅[扩展](extensions)。

## 键盘控制

整个聊天流程都可以用键盘完成：`Tab` 和 `Shift+Tab` 移动焦点，
`Escape` 关闭最上层的面板或对话框，滑动分页器、检查点链接和消息操作
都是可获得焦点的控件。完整列表请参阅[键盘快捷键](keyboard-shortcuts)。
