本页说明 NeoTavern 中的主题如何工作：它们能改变什么、如何安装和切换，
以及安全模式如何保护你。

## 主题能改变什么

主题有三个层级：

- **设计令牌** —— 颜色、字体、间距、圆角、阴影和动画时长。
- **组件皮肤** —— 按钮、面板和其他控件的外观。
- **外壳布局** —— 命名区域的排布：导航、角色浏览器、聊天视口、侧面板和
  模态层。

这意味着主题是完整的视觉改造，而不仅仅是换色。一个主题可以把应用重新
装扮成游戏主机、视觉小说或移动客户端，而不改变任何聊天逻辑。切换主题、
组件皮肤或外壳布局永远不需要重启。

## 内置主题

首次运行会预置一组内置主题，包括 AMOLED、GitHub Dark、Matrix、Nord、
Gruvbox、Dracula、Tokyo Night 和 Catppuccin Mocha。主题管理器始终以这些
主题可用为起点打开，因此你可以立即切换样式。

## 安装主题

主题包是一个 `.sttheme` 文件 —— 一个包含 `theme.json` 清单和 CSS 的 ZIP，
最大 25 MB。通过主题管理器安装：

1. 从导航栏或设置 → 主题选项卡打开"主题"。
2. 安装软件包。服务器在写入任何内容之前会验证路径、文件类型、大小和清单，
   并拒绝遍历路径、符号链接和禁止的 CSS。
3. 在应用前预览主题。从预览中你可以接受主题、返回或打开其设置。
4. 激活它。安装本身绝不会自动激活主题。

已安装主题的更新会原子地替换它并保持其激活状态。如果主题加载失败，
外壳会自动恢复最后一次可用的布局。

## 自定义主题

主题是软件包，而不是黑客手段：主题无法访问你的聊天记录、API 密钥或
文件系统。主题 SDK 记录了主题所修饰的稳定钩子 —— `data-component`、
`data-part`、`data-role` 和 `data-state` —— 以及定义命名区域的外壳契约。
自定义 CSS 覆盖在级联中最后加载。构建自己的主题请参阅
[主题 SDK](../developers/theme-sdk/) 参考。

## 安全模式与恢复

安全模式禁用所有第三方主题和插件，并且可以在它们加载之前进入，
因此损坏的主题绝不会把你锁在门外。崩溃循环之后应用会自动提供安全启动。
内置的**重置界面**操作无需手工编辑文件即可恢复默认主题，
任何主题都不允许隐藏该操作。

活动主题和消息样式选项所在的"常规"选项卡请参阅[设置](settings)。
