本页列出 NeoTavern 中的默认键盘快捷键。整个应用都可以用键盘操作，
每个模态框在关闭前都会把焦点保持在自身内部。

## 输入框

| 操作           | 快捷键                     |
| -------------- | -------------------------- |
| 发送消息       | `Enter`                    |
| 插入新行       | `Shift+Enter`              |
| 打开聊天搜索   | 聚焦聊天标题中的搜索字段   |
| 滚动到最新消息 | 向上滚动后使用"新消息"操作 |

输入框提示始终显示当前模式，因此你可以一眼看出 `Enter` 是发送还是换行。

## 编辑消息

| 操作     | 快捷键                                               |
| -------- | ---------------------------------------------------- |
| 保存编辑 | `Ctrl+Enter`（Windows/Linux）或 `Cmd+Enter`（macOS） |
| 取消编辑 | `Escape`                                             |

编辑是非破坏性的：之前的内容会归档到消息的编辑历史中，冲突时会保留你的
草稿而不是覆盖。请参阅[聊天](chat)。

## 导航和面板

| 操作                           | 快捷键                                              |
| ------------------------------ | --------------------------------------------------- |
| 关闭最上层的面板、对话框或菜单 | `Escape`                                            |
| 向前 / 向后移动焦点            | `Tab` / `Shift+Tab`                                 |
| 关闭感知路由的界面             | 浏览器后退                                          |
| 调整可调整大小的面板           | 焦点在调整大小手柄上时按 `ArrowLeft` / `ArrowRight` |
| 打开和关闭导航菜单             | 导航栏切换按钮                                      |

`Escape` 首先关闭最上层的界面：嵌套对话框先于其后面的面板关闭，
焦点会返回到打开它的控件。

## 聊天操作

| 操作               | 快捷键                                      |
| ------------------ | ------------------------------------------- |
| 在滑动变体之间切换 | `N/M` 分页器中的上一个 / 下一个箭头         |
| 打开检查点快照     | 点击检查点标记（或 `Shift+Click` 创建新的） |
| 手动排除或恢复消息 | 消息栏中的排除操作（手动上下文策略）        |

消息操作在桌面上始终可见，在移动端分组到紧凑的消息卡片中；每个操作都是
可获得焦点的控件，因此没有任何操作需要悬停或指针。

## 插件快捷键

插件通过插件 SDK 注册其快捷键，SDK 会解决冲突，让最新激活的注册胜出，
并在插件被禁用时释放绑定。插件快捷键绝不会拦截系统浏览器的组合键，
命令面板会在上下文中列出每个命令的快捷键。请参阅
[扩展与插件](extensions)。
