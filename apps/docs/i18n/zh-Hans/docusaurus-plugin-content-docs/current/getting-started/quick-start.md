本页带你从全新安装到生成第一条消息，大约需要五分钟。你需要一个可用的
提供商；其他一切都是可选的。

## 1. 启动应用

打开 NeoTavern。主屏幕会直接打开，首次运行会显示一个非阻塞的检查清单，
让你选择语言和文字大小。你可以忽略这个清单，稍后再回来处理 ——
这里没有任何东西会阻塞角色画廊、导入或本地设置。

## 2. 连接提供商

生成回复需要一个提供商：你机器上的本地模型服务器或远程 API。
打开 AI 设置面板或提供商部分：

1. 选择 API 类型（例如 Chat Completions）和一个定义提供商的来源。
2. 输入你的 API 密钥。密钥存储在本地，保存后绝不会完整显示，
   默认也不会包含在导出中。
3. 可选：加载该提供商的模型列表并选择一个模型。
4. 使用**测试连接**验证可用性和延迟，然后点击**连接**激活配置文件。

还没有提供商？选择内置的 **Echo** 提供商即可离线测试完整流程。
Echo 会回复一段预设的应答，不需要密钥，也不需要网络访问。

当没有激活的提供商时，发送按钮会被禁用，旁边会显示原因。
提供商错误绝不会把你锁在自己的本地资料库之外。

## 3. 选择或创建角色

从导航栏打开"角色"部分：

- 浏览画廊并打开一张卡片开始聊天。
- 从磁盘导入角色卡（PNG 或 JSON）。
- 从零开始创建一个新角色 —— 只需要一个名字。

完整细节请参阅[角色](../user-guide/characters)。

## 4. 发送你的第一条消息

选择角色后，聊天画布会打开，角色的开场白会作为第一条助手消息显示。
在下方输入内容并按 `Enter` 发送。只有在发送第一条非空消息后，聊天才会
在后端创建，因此浏览过程不会留下空的聊天记录。

回复会在生成的同时流式显示。你可以随时停止它，也可以在流式输出过程中
回滚查看历史。聊天视图的全部功能请参阅[聊天](../user-guide/chat)。

- 如果后端无法启动或端口已被占用，请参阅[故障排除](troubleshooting)。
- 调整生成参数和连接配置文件，请参阅[设置](../user-guide/settings)。
