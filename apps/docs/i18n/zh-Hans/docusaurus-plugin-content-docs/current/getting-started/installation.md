本页说明如何在 Windows、macOS 和 Linux 上安装 NeoTavern。请从
[GitHub 发布页](https://github.com/Disya123/NeoTavern/releases) 下载适合你
平台的构建版本。

## 安装目标

- **Windows 安装程序。** 一个安装可执行文件，负责安装应用并添加快捷方式。
  推荐大多数 Windows 用户使用。
- **Windows 便携版。** 一个自包含文件夹，无需安装任何东西即可运行。
  它把所有数据保存在自己的目录中，因此你可以把它放在 U 盘里随身携带。
- **macOS 软件包。** 一个标准的 `.app` 应用包。把它拖入"应用程序"文件夹
  并从那里启动即可。
- **Linux AppImage 和压缩包。** AppImage 可以在大多数桌面发行版上运行。
  压缩包变体是一个普通文件夹，你可以把它放在任何位置，双击即可启动。

四个目标版本在功能上完全一致。选择最适合你管理软件习惯的那一种即可。

## 系统要求

- 64 位桌面操作系统：Windows 10 或更新版本、macOS 或主流 Linux 发行版。
- 足够的运行内存和磁盘空间来存放你的资料库。空闲状态下后端在参考机器上
  占用约 180 MB 内存，应用在同一台机器上约四秒即可进入就绪界面。
- 不需要单独安装 Node.js、Python、SQLite 或浏览器。应用所需的一切都已内置。

## 内置了什么

发行版内嵌了 Node.js 24 LTS 和 SQLite，桌面外壳将本地后端作为内嵌的
sidecar 进程运行。这意味着：

- 首次运行绝不会执行 `npm install`，也绝不需要终端。
- 后端只绑定 `127.0.0.1`。局域网或远程访问绝不会被静默启用；
  它需要显式选择加入。
- 关闭应用窗口会优雅地关闭 sidecar，因此不会留下任何后端进程。

## 安装之后

首次启动会创建你的数据目录、填充一个小的起始资料库，并打开主屏幕。
后续步骤请参阅[快速开始](quick-start)。

如果在安装或首次运行期间出现问题，请参阅[故障排除](troubleshooting)。
