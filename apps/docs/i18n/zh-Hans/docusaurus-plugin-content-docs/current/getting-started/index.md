NeoTavern 是一个运行在你自己的电脑上的本地优先 AI 聊天与角色扮演平台。
你可以创建或导入角色，通过你连接的任何 AI 模型与他们对话，并把每条消息、
每张角色卡和每项设置都保存在你的机器上。

## 本地优先的设计

- 你的数据存放在电脑上的本地数据目录中。没有账户、没有强制云同步，
  默认也没有遥测。
- 你可以在离线状态下浏览资料库、编辑角色、查看设置。只有生成回复
  需要一个可访问的提供商。
- 在首次向外部 AI 服务发送任何内容之前，应用会明确告诉你哪个提供商
  将收到该请求。

## 运行方式

- 桌面应用支持 Windows、macOS 和 Linux。它内置了 Node.js 和 SQLite，
  你永远不需要自己安装运行时。
- 应用会启动自己的本地后端：一个内嵌的 Node.js sidecar 进程，默认监听
  `127.0.0.1:8000`，并随窗口一起关闭。
- 响应式 PWA 让手机和平板可以连接运行在你 PC 或家庭服务器上的后端。

## 你需要什么

- 一个受支持的 64 位桌面操作系统。整个过程不需要终端、Git 或包管理器。
- 一个用于生成回复的提供商：本地模型服务器，或带有你自己密钥的远程 API。
  内置的 Echo 提供商让你可以在离线状态下、不依赖任何外部服务地验证整个流程。
- 可选但有用：一份现有的 SillyTavern 数据备份，用于迁移你的角色、聊天记录、
  设定集和人设。
