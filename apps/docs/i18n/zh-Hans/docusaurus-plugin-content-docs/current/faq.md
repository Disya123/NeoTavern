本页回答用户最常问到的关于 NeoTavern 的问题。

## 我的数据存放在哪里？

你的所有数据 —— 聊天记录、角色、人设、群组、设定集、记忆和设置 —— 都存放在
你机器上的一个数据目录中。该目录包含 SQLite 数据库，以及保存角色卡、图像和
其他资源的文件存储。具体布局以及如何迁移数据，请参阅
[数据与存储](./developers/data/) 和[数据与备份](./user-guide/data-and-backups)。

## NeoTavern 可以离线使用吗？

可以。NeoTavern 是本地优先且支持离线的：把它指向一个本地模型端点，
你就可以在完全没有网络连接的情况下聊天。云提供商显然需要网络，
而当连接缺失时应用会提醒你。

## 我的数据会被发送到云端吗？

不会。你的聊天记录和文件都留在你的机器上。唯一的网络流量来自你显式配置的
请求 —— 即你为生成、语音和图像连接的提供商 —— 而且应用默认不发送任何遥测数据。

## 我需要 API 密钥吗？

只有当你选择连接的云提供商才需要。本地模型完全不需要密钥；你在设置中配置
每个提供商，密钥会保存在你的连接配置文件中。

## 插件安全吗？

插件在权限模型下运行并受到沙箱保护：后端插件在受限进程中执行，插件界面与
主应用隔离。你在安装时授予权限，如果出现问题，安全模式会在不加载插件和
主题的情况下启动应用。请参阅[扩展](./user-guide/extensions)和
[插件 SDK](./developers/plugin-sdk/)。

## 我可以使用现有的角色吗？

可以。NeoTavern 导入标准角色卡，包括内嵌 JSON 的 PNG 卡片，因此来自其他
聊天应用和社区角色画廊的角色开箱即用。请参阅[角色](./user-guide/characters)。

## 我可以迁移 SillyTavern 时代的插件吗？

针对旧版 SillyTavern 环境编写的插件可以通过旧版兼容层运行，该层提供熟悉的
`window.SillyTavern`、`window.eventSource` 和 `window.$` 全局对象，
以及一个兼容 Express 的 HTTP 主机。这是一条兼容路径，而不是重写目标：
新插件应使用[插件 SDK](./developers/plugin-sdk/)。请参阅
[旧版兼容](./developers/legacy-compat)。

## 更新是如何工作的？

更新就地安装并保留你的数据目录。更新日志列出了每个版本的变化；
更新前请先阅读，以便发现破坏性变更。

## 系统要求是什么？

NeoTavern 支持 Windows（安装程序或便携版）、macOS（软件包）和 Linux
（AppImage 或压缩包）。桌面应用自带 Node.js 运行时，因此你无需安装任何
其他东西。一台较新的 64 位操作系统和几百兆可用内存即可满足后端在典型
使用场景下的需求。

## 有网页版或移动版吗？

桌面应用基于 Tauri 构建，并附带一个 PWA 伴侣：网页界面可以作为渐进式
网页应用安装，带有离线应用外壳。请参阅[桌面端](./developers/desktop/)。

## 如何备份我的数据？

将聊天记录导出为文件、导出你的整个资料库，或者在应用停止时复制数据目录。
备份是普通、可移植的文件；通过导入或放回原位即可恢复。请参阅
[数据与备份](./user-guide/data-and-backups)和[备份](./developers/data/backups)。

## 什么是安全模式？

安全模式会在不加载插件和主题的情况下启动 NeoTavern，以便你排查由第三方
代码引起的问题。当安装插件或主题后应用无法启动时，请使用它。请参阅
[故障排除](./getting-started/troubleshooting)。

## 如何报告错误或请求功能？

在 [GitHub 仓库](https://github.com/Disya123/NeoTavern) 上提交 issue，
附上版本、操作系统和复现步骤。功能请求同样欢迎。

## 在哪里可以找到更新日志？

更新日志位于仓库中的
[CHANGELOG.md](https://github.com/Disya123/NeoTavern/blob/main/CHANGELOG.md)。
