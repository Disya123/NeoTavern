Сайт документации поставляется на английском плюс восемь локалей, и каждый
перевод — вклад сообщества. На этой странице объясняется, как внести перевод
или исправить существующий.

## Текущие локали

Базовый язык — английский. Переведённые локали: русский (`ru`), упрощённый
китайский (`zh-Hans`), японский (`ja`), корейский (`ko`), испанский (`es`),
французский (`fr`), немецкий (`de`) и бразильский португальский (`pt-BR`).

## Где живут переводы

Каждая локаль зеркалит английское дерево в `apps/docs/i18n/`:

```
apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/<path>.md
```

Строки UI — навбар, футер, теглайн и метки сайдбара — живут в JSON-файлах в
`apps/docs/i18n/<locale>/docusaurus-theme-classic/`, генерируемых командой
write-translations.

## Полнота

У каждой английской страницы должен быть переведённый аналог по тому же
относительному пути. Непереведённые страницы автоматически переключаются на
английский, поэтому частичный прогресс виден сразу, — но стремитесь к полному
покрытию и никогда не отправляйте наполовину переведённые файлы.

## Что переводить

- Заголовки, текст, подписи и alt-текст.
- `title` и `description` из front matter; `sidebar_position` оставляйте
  идентичным.
- Метки `_category_.json`.

## Что оставлять без изменений

- Ссылки, ограждения кода, инлайн-код и синтаксис адмоншенов
  (`:::note` ... `:::`), байт в байт.
- Название продукта: NeoTavern никогда не переводится.
- Идентификаторы API, имена файлов, команды и флаги остаются в английской
  форме.

## Терминология

Используйте формулировку UI самого приложения, где она существует; в
противном случае используйте стандартный термин сообщества на вашем языке.
Если стандартный термин сообщества уже существует, предпочитайте его —
никогда не изобретайте новое слово.

## Исправление перевода

Отредактируйте файл вашей локали по тому же относительному пути и откройте
pull request. Когда меняется английский исходник страницы, обновите перевод
этой страницы в том же изменении.

## Добавление новой локали

1. Добавьте код локали и её отображаемую метку в `i18n.locales` и
   `localeConfigs` в `apps/docs/docusaurus.config.ts`.
2. Создайте каркас папки локали:

   ```bash
   pnpm docs:translations -- --locale <code>
   ```

3. Переведите каждую страницу в
   `apps/docs/i18n/<locale>/docusaurus-plugin-content-docs/current/` и
   сгенерированные JSON-файлы.
4. Откройте pull request, содержащий и изменение конфигурации, и новые файлы.

Коды локалей следуют стандартным соглашениям, например `zh-Hans` для
упрощённого китайского и `pt-BR` для бразильского португальского.
