В этом разделе объясняется, как NeoTavern хранит данные: база данных SQLite,
структура файловой системы для оригиналов и кэша и модель резервных копий.

## Каталог данных

Все пользовательские данные живут в одном локальном каталоге данных:

```text
data/
  app.db
  files/{avatars,backgrounds,attachments,audio,generated}/
  plugins/  themes/  cache/thumbnails/  backups/  logs/
```

## Страницы этого раздела

- [Хранилище SQLite](data/sqlite) — прагмы, STRICT-таблицы, поиск FTS5, стабильные
  UUIDv7-идентификаторы и миграции.
- [Файлы и изображения](data/files-and-images) — как оригиналы и пересоздаваемые
  миниатюры хранятся и записываются атомарно.
- [Резервные копии](data/backups) — модель резервных копий, восстановление и то,
  что покрывают резервные копии.
