Десктоп-приложение — это нативный дистрибутив NeoTavern: оболочка Tauri 2,
которая запускает backend Fastify как встроенный sidecar на Node.js.

## Одно приложение, без настройки

Десктопный дистрибутив самодостаточен. Node.js, SQLite и продакшн-веб-ресурсы
упакованы внутрь пакета, поэтому первый запуск не требует терминала, Git,
npm или ручной настройки базы данных. Вы устанавливаете приложение,
запускаете его, и webview открывается, как только локальный API готов.

Компоненты рантайма:

- **Оболочка Tauri 2** — нативное окно и жизненный цикл приложения.
- **Sidecar на Node.js** — самодостаточный бинарник Node.js 24, который
  запускает backend Fastify локально на `127.0.0.1`.
- **SQLite** — локальная база данных, автоматически создаваемая в каталоге
  данных при первом запуске.

## Поддерживаемые форматы

Десктопная сборка нацелена на форматы, которые ожидает большинство
пользователей:

- Установщик Windows (NSIS и MSI).
- Портативная сборка Windows (ZIP с портативным флагом).
- Пакет macOS (`.app`, плюс DMG).
- AppImage Linux и архив.

Каждый формат собирается на нативном раннере своей платформы, потому что
дистрибутив включает нативные аддоны, такие как `better-sqlite3` и Sharp.
Подробности форматов и поведение первого запуска см. в [Упаковка](packaging.md).

## Гарантии жизненного цикла

Оболочка и sidecar — одно целое. Закрытие окна завершает backend — приложение
никогда не оставляет осиротевший процесс Node.js. Неожиданный выход backend
завершает оболочку с ошибкой, а не молча сломанным окном. О механике см.
[Оболочка Tauri](tauri-shell.md) и [Sidecar на Node.js](node-sidecar.md).

## Расположение данных

Установленные сборки хранят пользовательские данные в каталоге app-local-data
платформы, никогда не внутри пакета. Исключение — портативная сборка: при
наличии портативного флага данные живут в локальной папке `data/` рядом с
приложением. Обработка данных сама по себе описана в разделе
[Данные и хранилище](../data/index.md).
