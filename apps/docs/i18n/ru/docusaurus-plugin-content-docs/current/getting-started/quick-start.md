Эта страница проведёт вас от свежей установки до первого сгенерированного
сообщения примерно за пять минут. Вам нужен активный провайдер; всё остальное
необязательно.

## 1. Запустите приложение

Откройте NeoTavern. Сразу открывается домашний экран, а при первом запуске
показывается ненавязчивый чек-лист, в котором вы выбираете язык и масштаб
текста. Чек-лист можно проигнорировать и вернуться к нему позже — ничто из
этого не блокирует галерею персонажей, импорт или локальные настройки.

## 2. Подключите провайдера

Для генерации нужен провайдер: локальный сервер моделей на вашей машине или
удалённый API. Откройте панель AI Settings или раздел Providers:

1. Выберите тип API (например, Chat Completions) и источник, который
   определяет провайдера.
2. Введите API-ключ. Ключи хранятся локально, после сохранения никогда не
   показываются полностью и по умолчанию не попадают в экспорт.
3. При желании загрузите список моделей этого провайдера и выберите модель.
4. Используйте **Test Connection** для проверки доступности и задержки,
   затем **Connect**, чтобы активировать профиль.

Пока нет провайдера? Выберите встроенный провайдер **Echo**, чтобы проверить
весь конвейер офлайн. Echo отвечает готовой фразой и не требует ключа или
доступа к сети.

Пока ни один провайдер не активен, кнопка отправки неактивна, и рядом с ней
приложение объясняет причину. Ошибки провайдеров никогда не блокируют доступ
к вашей локальной библиотеке.

## 3. Выберите или создайте персонажа

Откройте раздел Characters с навигационной панели:

- Просмотрите галерею и откройте карточку, чтобы начать чат.
- Импортируйте карточку персонажа (PNG или JSON) с диска.
- Создайте персонажа с нуля — для этого достаточно одного имени.

Полные подробности см. в разделе [Персонажи](../user-guide/characters).

## 4. Отправьте первое сообщение

Когда персонаж выбран, открывается холст чата с приветствием персонажа в
качестве первого сообщения ассистента. Введите текст ниже и нажмите `Enter`,
чтобы отправить. Чат создаётся в backend только после отправки первого
непустого сообщения, поэтому просмотр не оставляет пустых чатов.

Ответ стримится по мере генерации. Вы можете остановить его в любой момент
или прокрутить историю назад во время стриминга. Всё, что умеет окно чата,
описано в разделе [Чат](../user-guide/chat).
