На этой странице объясняется, как установить NeoTavern на Windows, macOS и
Linux. Скачайте сборку для своей платформы со
[страницы релизов GitHub](https://github.com/Disya123/NeoTavern/releases).

## Варианты установки

- **Установщик для Windows.** Устанавливаемый исполняемый файл, который
  ставит приложение и добавляет ярлыки. Рекомендуется большинству
  пользователей Windows.
- **Портативная сборка Windows.** Самодостаточная папка, которая работает
  без установки. Она хранит все данные внутри своего каталога, поэтому её
  можно носить с собой на USB-накопителе.
- **Пакет macOS.** Стандартный пакет `.app`. Перетащите его в папку
  Applications и запускайте оттуда.
- **AppImage и архив для Linux.** AppImage работает в большинстве десктопных
  дистрибутивов. Вариант с архивом — обычная папка, которую можно разместить
  где угодно и запустить двойным щелчком.

Все четыре варианта функционально идентичны. Выбирайте тот, который
соответствует тому, как вы управляете программным обеспечением на своей
машине.

## Системные требования

- 64-битная десктопная ОС: Windows 10 или новее, macOS или распространённый
  дистрибутив Linux.
- Достаточно памяти и места на диске для вашей библиотеки. В режиме простоя
  backend занимает около 180 МБ оперативной памяти на эталонной машине, а
  приложение доходит до готового интерфейса примерно за четыре секунды на
  той же машине.
- Отдельные Node.js, Python, SQLite или браузер не нужны. Всё необходимое
  приложению уже встроено.

## Что входит в дистрибутив

Дистрибутив включает Node.js 24 LTS и SQLite, а десктопная оболочка
запускает локальный backend как встроенный процесс sidecar. Это значит:

- Первый запуск никогда не выполняет `npm install` и не требует терминала.
- Backend привязывается только к `127.0.0.1`. Доступ из локальной сети или
  удалённо никогда не включается незаметно — для этого требуется явное
  согласие.
- Закрытие окна приложения корректно завершает sidecar, поэтому процессов
  backend в фоне не остаётся.

## После установки

Первый запуск создаёт каталог данных, наполняет небольшую стартовую
библиотеку и открывает домашний экран. Следующие шаги описаны в разделе
[Быстрый старт](quick-start).

Если при установке или первом запуске что-то пошло не так, см.
[Устранение неполадок](troubleshooting).
