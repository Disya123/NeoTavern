NeoTavern — это локально-ориентированная платформа для AI-чатов и ролевых
игр, которая работает на вашем компьютере. Вы создаёте или импортируете
персонажей, общаетесь с ними через любую подключённую AI-модель, а каждое
сообщение, карточка персонажа и настройка остаются на вашей машине.

## Локально-ориентированность по замыслу

- Ваши данные хранятся в локальном каталоге данных на вашем компьютере. Ни
  аккаунта, ни обязательной облачной синхронизации, ни телеметрии по
  умолчанию.
- Вы можете просматривать библиотеку, редактировать персонажей и проверять
  настройки офлайн. Генерация требует только доступного провайдера.
- Перед тем как данные впервые отправятся во внешний AI-сервис, приложение
  показывает, какой именно провайдер получит запрос.

## Как это работает

- Десктоп-приложение доступно для Windows, macOS и Linux. Оно включает
  Node.js и SQLite, так что рантайм устанавливать самостоятельно не
  придётся.
- Приложение запускает собственный локальный backend — встроенный sidecar на
  Node.js, который по умолчанию слушает `127.0.0.1:8000` и завершается
  вместе с окном.
- Адаптивный PWA позволяет телефонам и планшетам подключаться к backend,
  работающему на вашем ПК или домашнем сервере.

## Что вам понадобится

- Поддерживаемая 64-битная десктопная ОС. Терминал, Git или менеджер пакетов
  не требуются ни на одном этапе.
- Провайдер для генерации ответов: локальный сервер моделей или удалённый
  API с вашим ключом. Встроенный провайдер Echo позволяет проверить весь
  путь офлайн, без внешних сервисов.
- Необязательно, но полезно: существующая резервная копия данных SillyTavern
  для переноса персонажей, чатов, лорбуков и персон.
