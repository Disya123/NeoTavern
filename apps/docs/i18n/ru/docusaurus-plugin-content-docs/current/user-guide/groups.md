Эта страница объясняет, что такое группы и как NeoTavern обрабатывает
диалоги с несколькими персонажами сегодня.

## Что такое группа

Группа — это единый диалог, в котором участвуют несколько персонажей. Если в
обычном чате один персонаж плюс ваша персона, то в групповом чате происходит
переключение между персонажами, чтобы каждый ответ мог исходить от другого
участника.

## Группы в NeoTavern сегодня

Базовая модель чата NeoTavern — один персонаж на диалог, поверх которого
накладывается ваша персона. Отдельная функция групповых чатов, позволяющая
создавать диалог и переключать его участников в приложении, **запланирована**;
в текущем релизе её нет, поэтому эта страница описывает то, что работает
сегодня.

## Импортированные групповые чаты

При переносе резервной копии SillyTavern через Settings → Data групповые
чаты обрабатываются безопасно:

- Определения групп и их транскрипты импортируются как обычные чаты, а
  исходная запись группы сохраняется в метаданных чата.
- Транскрипт сохраняет каждое имя участника, сообщение и вариант свайпа,
  поэтому история с несколькими персонажами остаётся читаемой, и вы можете
  продолжить диалог.
- Неподдерживаемые категории явно перечисляются в отчёте об импорте, а не
  молча отбрасываются.

## Работа с несколькими персонажами сейчас

Пока нативные группы запланированы, типичные сценарии с несколькими
персонажами покрывают следующие возможности:

- **Отдельные чаты для каждого персонажа.** У каждого персонажа своя история
  чата, а панель Chats ограничивает список текущим персонажем.
- **Общий мир через лорбуки.** Привяжите лорбук к нескольким персонажам,
  чтобы согласованные знания о мире достигали каждого диалога. См.
  [Лорбуки](lorebook).
- **Ветвления сюжета.** Используйте чекпоинты и ветки, чтобы исследовать
  расходящиеся пути с любым персонажем, не теряя основной диалог. См.
  [Чат](chat).
- **Персоны.** Переключайте свою персону для каждого чата, чтобы менять то,
  как вы себя представляете в каждом диалоге.

Если вам нужен настоящий диалог с несколькими персонажами, имейте в виду
подход с импортированным групповым чатом: он сохраняет вашу существующую
групповую историю, а запланированная нативная функция будет строиться на тех
же данных.
