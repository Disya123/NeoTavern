Эта страница объясняет, где в NeoTavern находятся настройки и как
настраивать провайдеров, профили подключения и API-ключи.

## Где находятся настройки

В NeoTavern нет отдельной страницы настроек. Всё открывается панелью или
модальным окном поверх рабочего пространства чата, а закрытие возвращает вас
к тому же чату и черновику:

- **Settings** (с навигационной панели) группирует общие параметры
  приложения по вкладкам: **General** (язык, масштаб текста, стартовый
  экран, стиль сообщений, форма аватара, доступность), **Themes**
  (установка и активация тем) и **Data** (миграция, резервные копии,
  обслуживание кэша, диагностика).
- **AI Settings** — контекстная панель генерации. Её вкладка **Config**
  содержит параметры запроса активной модели: размер контекста, длину
  ответа, стриминг, сэмплирование, штрафы, seed и рассуждения. Вкладка
  **API** управляет профилями подключения и ключами, а **Advanced** собирает
  пользовательские шаблоны чата и инструкций из ChatML, Llama 3 или Alpaca.

Изменения настроек применяются немедленно там, где их легко отменить.
Параметры, отличающиеся от значений по умолчанию, помечаются и могут быть
сброшены по отдельности, а поиск по настройкам охватывает названия,
описания и ключевые слова.

## Глобальные и початовые настройки

Глобальные настройки в разделе **Settings** применяются ко всему приложению:
язык, тема, управление данными и значения по умолчанию. Початовое поведение
находится рядом с чатом: параметры генерации, активный провайдер и модель и
стратегия контекста редактируются в панели AI Settings, пока чат остаётся
открытым, а черновики и позиция прокрутки сохраняются. Персона тоже
початовая — каждый диалог может использовать другую персону, при этом
активная персона приложения остаётся значением по умолчанию.

## Провайдеры и профили подключения

Профиль подключения объединяет всё необходимое для общения с провайдером:
тип и источник API, базовый URL там, где это применимо, выбранный API-ключ и
модель. Вкладка **API** в AI Settings (и раздел Providers) позволяет:

1. Выбрать верхнеуровневый API (Chat Completions или Text Completions).
2. Выбрать источник, который фильтрует источники этого API и становится
   именем профиля.
3. Ввести базовый URL для серверов, совместимых с OpenAI, обычно
   заканчивающийся на `/v1`.
4. Выбрать или ввести идентификатор модели, при желании сначала загрузив
   список моделей.
5. Нажать **Test Connection**, чтобы проверить доступность и задержку, а
   затем **Connect**, чтобы активировать профиль.

## API-ключи

Ключи хранятся локально в менеджере ключей, который держит несколько именованных
ключей для каждого провайдера, из которых активен один. Секреты проверяются
перед сохранением и после этого никогда не отображаются полностью — видимой
остаётся только маскированный суффикс. Экспорт и диагностика по умолчанию
исключают секреты, а ошибки провайдеров показываются как локализованные
сообщения с техническими деталями и trace ID в сворачиваемом блоке.
