На этой странице перечислены стандартные горячие клавиши NeoTavern. Всё
приложение управляется с клавиатуры, и каждое модальное окно удерживает
фокус внутри себя, пока вы его не закроете.

## Композер

| Действие                          | Сочетание                                                     |
| --------------------------------- | ------------------------------------------------------------- |
| Отправить сообщение               | `Enter`                                                       |
| Вставить новую строку             | `Shift+Enter`                                                 |
| Открыть поиск по чату             | Сфокусировать поле поиска в заголовке чата                    |
| Прокрутить к последнему сообщению | Использовать действие «новое сообщение» после прокрутки вверх |

Подсказка композера всегда показывает текущий режим, так что вы сразу
видите, отправляет ли `Enter` сообщение или добавляет строку.

## Редактирование сообщений

| Действие         | Сочетание                                            |
| ---------------- | ---------------------------------------------------- |
| Сохранить правку | `Ctrl+Enter` (Windows/Linux) или `Cmd+Enter` (macOS) |
| Отменить правку  | `Escape`                                             |

Редактирование не разрушает данные: предыдущее содержимое архивируется в
истории правок сообщения, а при конфликте сохраняется ваш черновик вместо
перезаписи. См. [Чат](chat).

## Навигация и панели

| Действие                                 | Сочетание                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------ |
| Закрыть верхнюю панель, диалог или меню  | `Escape`                                                                 |
| Переместить фокус вперёд / назад         | `Tab` / `Shift+Tab`                                                      |
| Закрыть поверхность, учитывающую маршрут | Кнопка «Назад» браузера                                                  |
| Изменить размер изменяемой панели        | `ArrowLeft` / `ArrowRight` при сфокусированном маркере изменения размера |
| Открыть и закрыть меню навигации         | Кнопка переключения панели                                               |

`Escape` сначала закрывает верхнюю поверхность: вложенный диалог закрывается
раньше панели за ним, а фокус возвращается к элементу управления, который
его открыл.

## Действия чата

| Действие                                     | Сочетание                                                           |
| -------------------------------------------- | ------------------------------------------------------------------- |
| Переключение вариантов свайпа                | Стрелки «предыдущий» / «следующий» в пагинаторе `N/M`               |
| Открыть снимок чекпоинта                     | Клик по флажку чекпоинта (`Shift+Click` — создать новый)            |
| Исключить или восстановить сообщение вручную | Действие исключения в панели сообщения (ручная стратегия контекста) |

Действия сообщений всегда видны на десктопе и сгруппированы в компактной
карточке сообщения на мобильных устройствах; каждое действие — фокусируемый
элемент, поэтому ни одно не требует наведения или указателя.

## Горячие клавиши плагинов

Плагины регистрируют свои горячие клавиши через Plugin SDK, который
разрешает коллизии так, что побеждает новейшая активная регистрация, а при
отключении плагина привязка освобождается. Сочетания плагинов никогда не
перехватывают системные комбо браузера, а палитра команд показывает
сочетание каждой команды в контексте. См. [Расширения и плагины](extensions).
