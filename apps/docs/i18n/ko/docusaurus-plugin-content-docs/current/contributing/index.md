NeoTavern은 공개 프로젝트이며 모든 종류의 기여를 환영합니다. 버그
보고, 기능 요청, 코드, 문서, 번역이 여기 해당합니다.

## 기여 방법

- **버그를 보고하고 기능을 요청하세요.** 버전, OS, 재현 단계와 함께
  GitHub에 이슈를 여세요.
  [https://github.com/Disya123/NeoTavern/issues](https://github.com/Disya123/NeoTavern/issues)
- **코드를 작성하세요.** 이슈를 고르고, 댓글을 달고, 풀 리퀘스트를
  여세요. 변경을 작게 유지하고 [코드 가이드라인](contributing/code-guidelines)을
  따르세요.
- **문서를 개선하세요.** 공개 사이트는 `apps/docs`에 있습니다.
  [문서 사이트](contributing/docs-site)를 참조하세요.
- **번역하세요.** 여덟 개 로케일 중 하나를 돕거나 새 로케일을
  제안하세요. [번역](contributing/translations)을 참조하세요.

## 행동 강령

다른 기여자를 존중하세요. 리뷰와 이슈에서 건설적으로 행동하고,
선의를 가정하며, 논의를 작업에 집중하세요. 저장소의
[AGENTS.md](https://github.com/Disya123/NeoTavern/blob/main/AGENTS.md)는
프로젝트가 어떻게 구축되고 작업이 어떻게 완료되는지에 대한 권위
있는 설명입니다. 첫 변경 전에 읽어 보세요.

## 시작하기 전에

- 먼저 [개발 환경 구성](contributing/development-setup)과 [코드
  가이드라인](contributing/code-guidelines), 위에 연결된 AGENTS.md 파일을
  읽으세요.
- 하려는 일을 다루는 기존 이슈를 찾고, 큰 작업을 시작하기 전에
  댓글을 달아 관리자가 조기 피드백을 줄 수 있게 하세요.
- 풀 리퀘스트를 집중적으로 유지하세요. PR 하나에 논리적 변경 하나,
  테스트와 문서를 포함하세요.

## 제출 후 일어나는 일

관리자가 변경을 검토하고 CI가 품질 게이트인 린트, 타입체크, 테스트를
실행합니다. 모든 것이 통과하면 풀 리퀘스트가 병합되고 사용자에게
보이는 변경이 변경 로그에 들어갑니다.
