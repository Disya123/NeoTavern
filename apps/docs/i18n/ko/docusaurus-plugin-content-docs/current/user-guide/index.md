이 가이드는 NeoTavern에서 매일 하는 모든 작업을 다룹니다. 캐릭터와
채팅하고, 라이브러리를 구성하고, 생성 설정을 조정하고, 데이터를
안전하게 보관하는 방법입니다. 각 페이지는 독립적이므로 어디서부터
읽어도 됩니다.

## 가이드 구성 방식

사용자 가이드는 앱 자체의 구조를 따릅니다. NeoTavern은 채팅 우선
단일 워크스페이스를 유지합니다. 채팅 캔버스가 메인 화면이며, 그 외의
모든 것 — 캐릭터, 채팅, 로어북, 프로바이더, 테마, 플러그인, 설정 —
은 그 위에 패널이나 모달로 열립니다. 패널을 닫으면 떠났던 바로 그
채팅, 스크롤 위치, 초안으로 돌아가므로 아래 페이지들은 대화에서
벗어나는 상황을 가정하지 않습니다.

페이지들은 느슨한 순서로 서로 이어집니다.

## 섹션

- [채팅](user-guide/chat) — 메시지 보내기, 응답 스트리밍, 스와이프(대체 응답),
  다시 생성, 편집, 중지, 메시지 스냅샷. 핵심 상호작용을 이해하고 싶다면
  여기부터 읽으세요.
- [캐릭터](user-guide/characters) — 검색과 필터가 있는 캐릭터 갤러리, 캐릭터 카드
  필드, PNG 또는 JSON 카드 가져오기 및 내보내기.
- [그룹](user-guide/groups) — 여러 캐릭터가 참여하는 대화: 현재 제공되는 기능,
  마이그레이션을 통해 SillyTavern 그룹 채팅이 유입되는 방식, 계획된
  기능.
- [로어북](user-guide/lorebook) — 활성화 키워드가 일치할 때 프롬프트에 주입되는
  세계관 지식, 항목 설정, 삽입 순서, 캐릭터에 책 연결하기.
- [메모리 및 회상](user-guide/memory) — 누적되는 대화 메모리, 키워드로 활성화되는
  메모리 항목, 벡터 회상, RAG.
- [설정](user-guide/settings) — 전역 및 채팅별 설정이 있는 위치, 연결 프로필,
  프로바이더, 로컬 API 키 관리자.
- [테마](user-guide/themes) — 번들 및 사용자 지정 테마, 테마의 세 가지 레벨,
  설치와 전환, 세이프 모드.
- [확장 기능 및 플러그인](user-guide/extensions) — 플러그인 설치, 권한 및 동의
  흐름, 관리와 제거, 플러그인 안전성.
- [데이터 및 백업](user-guide/data-and-backups) — 데이터 디렉터리 구조, 내보내기와
  가져오기, SillyTavern 마이그레이션, 백업 생성과 복원.
- [키보드 단축키](user-guide/keyboard-shortcuts) — 입력, 편집, 탐색, 채팅 작업을
  위한 기본 단축키 표.

## 시작하기 전에

아직 앱을 설치하지 않았다면 [설치](getting-started/installation)부터
시작하세요. 새로 설치한 상태에서 첫 메시지까지 가려면
[빠른 시작](getting-started/quick-start)을 따르세요. 문제가 생기면
[문제 해결](getting-started/troubleshooting)을 확인하고, 자주 묻는
질문에 대한 짧은 답변은 [FAQ](faq)를 참조하세요.
