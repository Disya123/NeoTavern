이 페이지는 채팅 화면을 다룹니다. 메시지 작성과 전송, 응답이
스트리밍되는 모습, NeoTavern이 제공하는 메시지 작업에 대해
설명합니다.

## 메시지 보내기

입력창은 채팅 캔버스 하단에 있습니다. 메시지를 입력하고 `Enter`를
누르면 전송되며, `Shift+Enter`는 줄 바꿈입니다. 메시지는 즉시
표시되고 응답은 초당 최대 30회 UI 업데이트 배치로 화면에
스트리밍됩니다. 응답이 스트리밍되는 동안 기록을 스크롤할 수
있습니다. 자동 스크롤은 하단에 머물러 있을 때만 따라가며, 직접 위로
스크롤하면 "새 메시지" 작업이 나타납니다.

응답이 생성되는 동안 입력창의 메인 버튼은 **중지**로 바뀝니다.
중지하면 지금까지 받은 텍스트가 명시적으로 "불완전한 응답"으로
표시된 채 유지됩니다. 연결이 끊기면 재연결 옵션이 제공되며 중복
메시지가 생기지 않습니다.

초안은 채팅별로 저장되므로 다른 곳으로 갔다 와도 작성 중이던 내용이
사라지지 않습니다.

## 스와이프 (대체 메시지)

모든 어시스턴트 메시지는 스와이프라고 부르는 여러 대체 응답을 담을 수
있습니다. 메시지 아래의 페이지 표시줄이 `N/M` 형식의 개수와 이전/다음
화살표를 보여주며, 화살표를 클릭하면 변형을 하나도 잃지 않고
순환합니다. 스와이프 기록은 보존되며 파괴적이지 않습니다.

## 다시 생성

다시 생성 작업은 **최신** 어시스턴트 메시지를 제자리에서 다시
씁니다. 새 응답이 기존 말풍선으로 스트리밍되고, 이전 텍스트는 스와이프
페이지 표시줄의 또 다른 변형이 됩니다. 생성이 실패하거나 중지되면
이전 텍스트는 디스크에서 그대로 유지됩니다.

## 메시지 편집

메시지의 편집 작업을 열어 텍스트를 변경할 수 있습니다. 인라인
편집기는 `Ctrl+Enter`(macOS에서는 `Cmd+Enter`)로 저장하고 `Escape`로
취소합니다. 편집은 파괴적이지 않습니다. 이전 내용은 메시지의 편집
기록에 보관되며 언제든 복원할 수 있습니다. 편집 중 다른 곳에서
메시지가 변경되면 편집기는 초안을 유지한 채 조용히 덮어쓰는 대신
충돌 알림을 표시합니다.

## 메시지 작업

각 메시지의 작업 표시줄은 호버 시에만 나타나는 것이 아니라 항상
보입니다.

- 원시 메시지 텍스트 복사.
- 메시지 편집.
- 마지막 어시스턴트 응답 다시 생성.
- 변형 스와이프.
- **체크포인트** 또는 **브랜치** 만들기: 그 메시지 시점에 채팅을
  고정한 스냅샷을 자식 채팅으로 복사합니다. 체크포인트를 사용하면
  메인 대화를 건드리지 않고 스토리라인을 탐험할 수 있습니다.
- 메시지 삭제. 삭제된 채팅은 즉시 파괴되는 대신 휴지통 상태로
  이동합니다.

플러그인은 부여한 권한에 따라 같은 표시줄에 자체 작업을 추가할 수
있습니다. [확장 기능](extensions)을 참조하세요.

## 키보드 제어

채팅 흐름 전체를 키보드로 다룰 수 있습니다. `Tab`과 `Shift+Tab`은
포커스를 이동하고, `Escape`는 최상위 패널이나 대화상자를 닫으며,
스와이프 페이지 표시줄, 체크포인트 링크, 메시지 작업은 모두 포커스
가능한 컨트롤입니다. 전체 목록은 [키보드 단축키](keyboard-shortcuts)를
참조하세요.
