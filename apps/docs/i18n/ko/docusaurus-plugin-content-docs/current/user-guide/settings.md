이 페이지는 NeoTavern에서 설정이 어디에 있는지, 프로바이더와 연결
프로필, API 키를 구성하는 방법을 설명합니다.

## 설정 위치

NeoTavern에는 별도의 설정 페이지가 없습니다. 모든 것이 채팅
워크스페이스 위에 패널이나 모달로 열리며, 닫으면 정확히 같은 채팅과
초안으로 돌아갑니다.

- **설정**(내비게이션 레일에서 열림)은 앱 전체 옵션을 탭으로
  묶습니다. **일반**(언어, 텍스트 배율, 시작 화면, 메시지 스타일,
  아바타 모양, 접근성), **테마**(테마 설치 및 활성화), **데이터**
  (마이그레이션, 백업, 캐시 유지 관리, 진단)입니다.
- **AI 설정**은 생성에 관한 컨텍스트 패널입니다. **구성** 탭에는
  활성 모델의 요청 매개변수인 컨텍스트 크기, 응답 길이, 스트리밍,
  샘플링, 페널티, 시드, 추론이 있습니다. **API** 탭은 연결 프로필과
  키를 관리하고, **고급**은 ChatML, Llama 3, Alpaca를 기반으로 사용자
  지정 채팅 및 인스트럭트 템플릿을 만듭니다.

설정 변경은 쉽게 되돌릴 수 있는 곳에서는 즉시 적용됩니다. 기본값과
다른 옵션은 표시되며 개별적으로 초기화할 수 있고, 설정 검색은 이름,
설명, 키워드를 다룹니다.

## 전역 설정과 채팅별 설정

**설정**의 전역 설정은 앱 전체에 적용됩니다. 언어, 테마, 데이터 관리,
기본값이 여기에 해당합니다. 채팅별 동작은 채팅 옆에 있습니다. 생성
매개변수, 활성 프로바이더와 모델, 컨텍스트 전략은 채팅을 연 채로 AI
설정 패널에서 편집하며, 초안과 스크롤 위치는 보존됩니다. 페르소나도
채팅별입니다. 각 대화에서 다른 페르소나를 사용할 수 있으며, 앱 전체의
활성 페르소나는 기본값으로 유지됩니다.

## 프로바이더 및 연결 프로필

연결 프로필은 프로바이더와 대화하는 데 필요한 모든 것을 묶습니다.
API 유형과 소스, 해당하는 경우 기본 URL, 선택한 API 키, 모델입니다.
AI 설정의 **API** 탭(및 프로바이더 섹션)에서 다음을 할 수 있습니다.

1. 최상위 API를 선택합니다(Chat Completions 또는 Text
   Completions).
2. 소스를 선택합니다. 소스는 해당 API의 소스로 필터링되며 프로필
   이름이 됩니다.
3. OpenAI 호환 서버의 기본 URL을 입력합니다. 보통 `/v1`로 끝납니다.
4. 모델 ID를 선택하거나 입력하고, 선택적으로 모델 목록을 먼저
   불러옵니다.
5. **연결 테스트**로 가용성과 지연 시간을 확인한 뒤 **연결**을 눌러
   프로필을 활성화합니다.

## API 키

키는 프로바이더별로 이름 있는 여러 키를 보관하며 한 번에 하나씩
활성화되는 키 관리자에 로컬로 저장됩니다. 비밀은 저장 전에 검증되며,
이후에는 마스킹된 접미사만 보이고 전체가 표시되지 않습니다. 내보내기와
진단은 기본적으로 비밀을 제외하며, 프로바이더 오류는 접을 수 있는
블록 안에 기술 세부 정보와 추적 ID와 함께 지역화된 메시지로
표시됩니다.

나머지 앱 전체 설정은 [테마](themes), [확장 기능](extensions),
[데이터 및 백업](data-and-backups)을 참조하세요.
