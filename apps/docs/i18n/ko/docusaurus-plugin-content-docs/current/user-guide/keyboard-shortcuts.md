이 페이지는 NeoTavern의 기본 키보드 단축키를 정리합니다. 앱 전체를
키보드로 조작할 수 있으며, 모든 모달은 닫을 때까지 포커스를 내부에
유지합니다.

## 입력창

| 동작                 | 단축키                                 |
| -------------------- | -------------------------------------- |
| 메시지 보내기        | `Enter`                                |
| 줄 바꿈              | `Shift+Enter`                          |
| 채팅 검색 열기       | 채팅 헤더의 검색 필드에 포커스         |
| 최신 메시지로 스크롤 | 위로 스크롤한 뒤 "새 메시지" 작업 사용 |

입력창 힌트는 항상 현재 모드를 보여주므로 `Enter`가 보내기인지 줄
바꿈인지 한눈에 알 수 있습니다.

## 메시지 편집

| 동작      | 단축키                                                |
| --------- | ----------------------------------------------------- |
| 편집 저장 | `Ctrl+Enter` (Windows/Linux) 또는 `Cmd+Enter` (macOS) |
| 편집 취소 | `Escape`                                              |

편집은 파괴적이지 않습니다. 이전 내용은 메시지의 편집 기록에
보관되고, 충돌 시 덮어쓰는 대신 초안이 유지됩니다. [채팅](chat)을
참조하세요.

## 탐색 및 패널

| 동작                             | 단축키                                                        |
| -------------------------------- | ------------------------------------------------------------- |
| 최상위 패널, 대화상자, 메뉴 닫기 | `Escape`                                                      |
| 포커스 앞/뒤로 이동              | `Tab` / `Shift+Tab`                                           |
| 라우트 인식 표면 닫기            | 브라우저 뒤로 가기                                            |
| 크기 조절 가능한 패널 크기 변경  | 크기 조절 핸들에 포커스한 상태에서 `ArrowLeft` / `ArrowRight` |
| 내비게이션 메뉴 열기/닫기        | 레일 토글 버튼                                                |

`Escape`는 최상위 표면부터 닫습니다. 중첩 대화상자는 뒤의 패널보다 먼저
닫히며, 포커스는 열었던 컨트롤로 돌아갑니다.

## 채팅 작업

| 동작                   | 단축키                                             |
| ---------------------- | -------------------------------------------------- |
| 스와이프 변형 전환     | `N/M` 페이지 표시줄의 이전/다음 화살표             |
| 체크포인트 스냅샷 열기 | 체크포인트 플래그 클릭 (`Shift+Click`은 새로 생성) |
| 메시지 수동 제외/복원  | 메시지 표시줄의 제외 작업 (수동 컨텍스트 전략)     |

메시지 작업은 데스크톱에서 항상 표시되고, 모바일에서는 압축 메시지
카드에 모입니다. 모든 작업은 포커스 가능한 컨트롤이므로 호버나
포인터가 필요하지 않습니다.

## 플러그인 단축키

플러그인은 Plugin SDK를 통해 단축키를 등록하며, SDK가 충돌을 해결해
가장 최근의 활성 등록이 우선하고 플러그인이 비활성화되면 바인딩을
해제합니다. 플러그인 단축키는 시스템 브라우저 콤보를 가로채지 않으며,
명령 팔레트는 각 명령의 단축키를 상황에 맞게 나열합니다.
[확장 기능 및 플러그인](extensions)을 참조하세요.
