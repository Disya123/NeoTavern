이 페이지에서는 그룹이 무엇인지, 그리고 NeoTavern이 현재
여러 캐릭터가 참여하는 대화를 어떻게 처리하는지 설명합니다.

## 그룹이란?

그룹은 여러 캐릭터가 참여하는 단일 대화입니다. 일반 채팅은 한 명의
캐릭터와 내 페르소나로 이루어지지만, 그룹 채팅은 각 응답이 다른
참가자에게서 올 수 있도록 캐릭터 사이를 전환합니다.

## 현재 NeoTavern의 그룹

NeoTavern의 핵심 채팅 모델은 대화당 한 명의 캐릭터이며, 그 위에 내
페르소나가 얹히는 방식입니다. 앱에서 대화를 만들고 멤버를 전환할 수
있는 전용 그룹 채팅 기능은 **계획**되어 있습니다. 현재 릴리스에서는
사용할 수 없으므로, 이 페이지는 대신 지금 사용할 수 있는 기능을
설명합니다.

## 가져온 그룹 채팅

설정 → 데이터에서 SillyTavern 백업을 마이그레이션하면 그룹 채팅이
안전하게 처리됩니다.

- 그룹 정의와 대화 기록은 일반 채팅으로 가져와지며, 원래 그룹
  레코드는 채팅 메타데이터에 유지됩니다.
- 대화 기록에는 모든 참가자 이름, 메시지, 스와이프 변형이 보존되어
  여러 캐릭터 기록을 계속 읽을 수 있고 대화를 이어갈 수 있습니다.
- 지원되지 않는 범주는 조용히 버려지는 대신 가져오기 보고서에 명시적으로
  나열됩니다.

## 지금 여러 캐릭터와 작업하기

네이티브 그룹이 계획 중인 동안, 다음 기능이 일반적인 다중 캐릭터
워크플로를 다룹니다.

- **캐릭터별 별도 채팅.** 각 캐릭터는 자신의 채팅 기록을 유지하며,
  채팅 패널은 목록을 현재 캐릭터 범위로 제한합니다.
- **로어북을 통한 공유 세계관.** 여러 캐릭터에 로어북을 연결하면
  일관된 세계관 지식이 모든 대화에 도달합니다.
  [로어북](lorebook)을 참조하세요.
- **스토리라인 브랜치.** 체크포인트와 브랜치를 사용해 메인 대화를
  잃지 않고 어떤 캐릭터로든 갈라지는 경로를 탐험할 수 있습니다.
  [채팅](chat)을 참조하세요.
- **페르소나.** 채팅별로 내 페르소나를 전환해 각 대화에서 자신을
  표현하는 방식을 바꿀 수 있습니다.

진짜 다중 캐릭터 대화가 필요하다면 가져온 그룹 채팅 방식을 기억해
두세요. 기존 그룹 기록을 보존하며, 계획된 네이티브 기능도 같은
데이터를 기반으로 구축될 것입니다.
