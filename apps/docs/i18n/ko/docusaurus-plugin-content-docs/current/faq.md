이 페이지는 사용자가 NeoTavern에 대해 가장 자주 묻는 질문에 답합니다.

## 내 데이터는 어디에 저장되나요?

모든 데이터 — 채팅, 캐릭터, 페르소나, 그룹, 로어북, 메모리, 설정 — 은
내 기기의 데이터 디렉터리에 있습니다. 디렉터리에는 SQLite 데이터베이스와
캐릭터 카드, 이미지, 기타 에셋이 든 파일 저장소가 있습니다. 정확한
구조와 이동 방법은 [데이터 및 저장소](./developers/data/)와 [데이터 및
백업](./user-guide/data-and-backups)을 참조하세요.

## NeoTavern은 오프라인으로 동작하나요?

네. NeoTavern은 로컬 퍼스트이며 오프라인 사용이 가능합니다. 로컬 모델
엔드포인트를 지정하면 인터넷 연결 없이도 채팅할 수 있습니다. 클라우드
프로바이더는 당연히 네트워크가 필요하며, 앱은 연결이 없을 때 이를
알려줍니다.

## 내 데이터가 클라우드로 전송되나요?

아니요. 채팅과 파일은 내 기기에 남습니다. 유일한 네트워크 트래픽은
직접 구성한 요청 — 생성, 음성, 이미지를 위해 연결한 프로바이더 — 뿐이며,
앱은 기본적으로 텔레메트리를 보내지 않습니다.

## API 키가 필요한가요?

연결하기로 선택한 클라우드 프로바이더에만 필요합니다. 로컬 모델은 키가
전혀 필요 없습니다. 각 프로바이더는 설정에서 구성하며 키는 연결
프로필에 유지됩니다.

## 플러그인은 안전한가요?

플러그인은 권한 모델 아래에서 실행되고 샌드박스 처리됩니다. 백엔드
플러그인은 제한된 프로세스에서 실행되고 플러그인 UI는 메인 앱과
격리됩니다. 설치 시 권한을 부여하며, 문제가 생기면 세이프 모드가
플러그인과 테마 없이 앱을 시작합니다. [확장
기능](./user-guide/extensions)과 [Plugin SDK](./developers/plugin-sdk/)를
참조하세요.

## 기존 캐릭터를 사용할 수 있나요?

네. NeoTavern은 내장 JSON이 있는 PNG 카드를 포함해 표준 캐릭터
카드를 가져오므로 다른 채팅 앱과 커뮤니티 캐릭터 갤러리의 캐릭터가
바로 동작합니다. [캐릭터](./user-guide/characters)를 참조하세요.

## SillyTavern 시대 플러그인을 마이그레이션할 수 있나요?

이전 SillyTavern 환경에 맞춰 작성된 플러그인은 레거시 호환 계층을
통해 실행할 수 있습니다. 친숙한 `window.SillyTavern`,
`window.eventSource`, `window.$` 전역과 Express 호환 HTTP 호스트를
제공합니다. 그것은 호환 경로이지 재작성 대상이 아닙니다. 새
플러그인은 [Plugin SDK](./developers/plugin-sdk/)를 사용해야 합니다.
[레거시 호환성](./developers/legacy-compat)을 참조하세요.

## 업데이트는 어떻게 동작하나요?

업데이트는 제자리에 설치되며 데이터 디렉터리를 보존합니다. 변경
로그는 각 릴리스에서 바뀐 것을 정리합니다. 호환성이 깨지는 변경을
잡으려면 업데이트 전에 읽어 보세요.

## 시스템 요구 사항은 무엇인가요?

NeoTavern은 Windows(설치 프로그램 또는 포터블 빌드), macOS(패키지),
Linux(AppImage 또는 아카이브)에서 실행됩니다. 데스크톱 앱은 자체
Node.js 런타임을 번들하므로 다른 것을 설치할 필요가 없습니다. 최신
64비트 운영 체제와 백엔드용 수백 MB의 여유 RAM이면 일반적인
사용에 충분합니다.

## 웹 또는 모바일 버전이 있나요?

데스크톱 앱은 Tauri 위에 구축되며 PWA 동반 앱과 함께 제공됩니다. 웹
UI는 오프라인 앱 셸이 있는 프로그레시브 웹 앱으로 설치할 수
있습니다. [데스크톱](./developers/desktop/)을 참조하세요.

## 데이터를 백업하려면 어떻게 하나요?

채팅을 파일로 내보내거나, 전체 라이브러리를 내보내거나, 앱이 중지된
상태에서 데이터 디렉터리를 복사하세요. 백업은 일반적이고 휴대 가능한
파일이며, 가져오기 또는 제자리에 다시 놓는 것으로 복원합니다.
[데이터 및 백업](./user-guide/data-and-backups)과
[백업](./developers/data/backups)을 참조하세요.

## 세이프 모드란 무엇인가요?

세이프 모드는 플러그인과 테마 없이 NeoTavern을 시작해 타사 코드가
일으킨 문제를 진단할 수 있게 합니다. 플러그인이나 테마를 설치한 후
앱이 시작되지 않을 때 사용하세요. [문제
해결](./getting-started/troubleshooting)을 참조하세요.

## 버그를 보고하거나 기능을 요청하려면 어떻게 하나요?

버전, OS, 재현 단계와 함께 [GitHub
저장소](https://github.com/Disya123/NeoTavern)에 이슈를 여세요. 기능
요청도 거기서 받습니다.

## 변경 로그는 어디서 찾나요?

변경 로그는 저장소의
[CHANGELOG.md](https://github.com/Disya123/NeoTavern/blob/main/CHANGELOG.md)에
있습니다.
