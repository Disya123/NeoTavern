NeoTavern은 내 컴퓨터에서 실행되는 로컬 퍼스트 AI 채팅 및 롤플레이
플랫폼입니다. 캐릭터를 만들거나 가져오고, 연결한 AI 모델과 대화하며,
모든 메시지와 캐릭터 카드, 설정을 내 기기에 보관할 수 있습니다.

## 설계 원칙: 로컬 퍼스트

- 데이터는 컴퓨터의 로컬 데이터 디렉터리에 저장됩니다. 계정이 없고,
  강제 클라우드 동기화도 없으며, 기본적으로 텔레메트리도 수집하지
  않습니다.
- 오프라인에서도 라이브러리를 탐색하고, 캐릭터를 편집하고, 설정을
  검토할 수 있습니다. 연결 가능한 프로바이더가 필요한 것은 생성
  기능뿐입니다.
- 외부 AI 서비스로 데이터를 처음 보내기 전에, 앱은 어떤 프로바이더가
  요청을 받게 될지 정확히 보여줍니다.

## 실행 방식

- 데스크톱 앱은 Windows, macOS, Linux에서 사용할 수 있습니다. Node.js와
  SQLite가 함께 번들되어 있어 런타임을 직접 설치할 필요가 없습니다.
- 앱은 자체 로컬 백엔드를 시작합니다. 기본적으로 `127.0.0.1:8000`에서
  수신 대기하는 내장 Node.js 사이드카이며, 창을 닫으면 함께 종료됩니다.
- 반응형 PWA를 통해 휴대폰이나 태블릿에서 PC 또는 홈 서버에서 실행
  중인 백엔드에 연결할 수 있습니다.

## 필요한 것

- 지원되는 64비트 데스크톱 OS. 어느 단계에서도 터미널, Git, 패키지
  매니저가 필요하지 않습니다.
- 응답을 생성할 프로바이더: 로컬 모델 서버 또는 키를 가진 원격 API.
  기본 제공되는 Echo 프로바이더는 외부 서비스 없이 오프라인으로 전체
  흐름을 검증할 수 있게 해줍니다.
- 선택 사항이지만 유용한 것: 캐릭터, 채팅, 로어북, 페르소나를
  마이그레이션할 기존 SillyTavern 데이터 백업.
