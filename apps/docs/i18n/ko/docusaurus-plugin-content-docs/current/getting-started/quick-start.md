이 페이지는 새로 설치한 상태에서 약 5분 만에 첫 생성 메시지를 보낼
때까지 안내합니다. 활성 프로바이더가 필요하며, 그 외에는 모두 선택
사항입니다.

## 1. 앱 실행

NeoTavern을 엽니다. Home 화면이 바로 열리며, 첫 실행에서는 언어와
텍스트 배율을 선택하는 비차단 체크리스트가 표시됩니다. 체크리스트는
무시하고 나중에 돌아와도 됩니다. 어떤 항목도 캐릭터 갤러리, 가져오기,
로컬 설정을 막지 않습니다.

## 2. 프로바이더 연결

생성에는 프로바이더가 필요합니다. 내 기기의 로컬 모델 서버 또는 원격
API를 사용할 수 있습니다. AI 설정 패널 또는 프로바이더 섹션을
여세요.

1. API 유형(예: Chat Completions)과 소스를 선택합니다. 소스가
   프로바이더를 정의합니다.
2. API 키를 입력합니다. 키는 로컬에 저장되며, 저장 후에는 전체가
   표시되지 않고 기본적으로 내보내기에도 포함되지 않습니다.
3. 선택적으로 해당 프로바이더의 모델 목록을 불러와 모델을
   선택합니다.
4. **연결 테스트**로 가용성과 지연 시간을 확인한 뒤 **연결**을 눌러
   프로필을 활성화합니다.

아직 프로바이더가 없나요? 기본 제공 **Echo** 프로바이더를 선택하면
오프라인에서 전체 파이프라인을 테스트할 수 있습니다. Echo는 정해진
문자열을 그대로 돌려주며 키나 네트워크 접근이 필요 없습니다.

활성 프로바이더가 없으면 보내기 버튼이 비활성화되고, 앱은 그 옆에
이유를 표시합니다. 프로바이더 오류로 로컬 라이브러리에 접근하지 못하는
일은 없습니다.

## 3. 캐릭터 선택 또는 생성

내비게이션 레일에서 캐릭터 섹션을 엽니다.

- 갤러리를 탐색하고 카드를 열어 채팅을 시작합니다.
- 디스크에서 캐릭터 카드(PNG 또는 JSON)를 가져옵니다.
- 처음부터 새 캐릭터를 만듭니다. 이름만 있으면 됩니다.

자세한 내용은 [캐릭터](../user-guide/characters)를 참조하세요.

## 4. 첫 메시지 보내기

캐릭터를 선택하면 캐릭터의 인사말이 첫 어시스턴트 메시지로 표시된 채팅
캔버스가 열립니다. 아래에 입력하고 `Enter`를 눌러 보내세요. 채팅은 첫
번째 비어 있지 않은 메시지를 보낸 후에만 백엔드에 생성되므로, 탐색만
하다가 빈 채팅이 남는 일이 없습니다.

응답은 생성되면서 스트리밍됩니다. 언제든 중지할 수 있고, 스트리밍 중에도
기록을 스크롤해 볼 수 있습니다. 채팅 화면이 할 수 있는 모든 것은
[채팅](../user-guide/chat)에서 확인하세요.
