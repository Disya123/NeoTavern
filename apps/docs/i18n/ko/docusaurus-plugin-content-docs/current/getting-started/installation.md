이 페이지에서는 Windows, macOS, Linux에 NeoTavern을 설치하는 방법을
설명합니다. 플랫폼에 맞는 빌드를
[GitHub 릴리스 페이지](https://github.com/Disya123/NeoTavern/releases)에서
내려받으세요.

## 설치 대상

- **Windows 설치 프로그램.** 앱을 설치하고 바로 가기를 추가하는 셋업
  실행 파일입니다. 대부분의 Windows 사용자에게 권장됩니다.
- **포터블 Windows 빌드.** 아무것도 설치하지 않고 실행되는 독립
  폴더입니다. 모든 데이터를 자체 디렉터리 안에 보관하므로 USB 드라이브에
  담아 휴대할 수 있습니다.
- **macOS 패키지.** 표준 `.app` 번들입니다. Applications 폴더로 끌어다
  놓고 실행하면 됩니다.
- **Linux AppImage 및 아카이브.** AppImage는 대부분의 데스크톱
  배포판에서 실행됩니다. 아카이브 버전은 어디에나 둘 수 있고 더블
  클릭으로 실행하는 일반 폴더입니다.

네 가지 대상 모두 기능적으로 동일합니다. 내 기기에서 소프트웨어를
관리하는 방식에 맞는 것을 선택하세요.

## 시스템 요구 사항

- 64비트 데스크톱 OS: Windows 10 이상, macOS, 또는 주류 Linux
  배포판.
- 라이브러리를 저장할 충분한 메모리와 디스크 공간. 기준 머신에서 유휴
  백엔드는 약 180 MB의 RAM을 사용하며, 같은 머신에서 앱은 약 4초 만에
  준비된 UI에 도달합니다.
- 별도의 Node.js, Python, SQLite, 브라우저 설치는 필요 없습니다. 앱이
  필요한 모든 것이 함께 번들됩니다.

## 번들 구성

배포판에는 Node.js 24 LTS와 SQLite가 내장되어 있으며, 데스크톱 셸은
로컬 백엔드를 내장 사이드카 프로세스로 실행합니다. 즉:

- 첫 실행에서 `npm install`을 실행하지 않으며 터미널도 필요하지
  않습니다.
- 백엔드는 `127.0.0.1`에만 바인딩됩니다. LAN 또는 원격 접근은 절대
  조용히 활성화되지 않으며 명시적인 동의가 필요합니다.
- 앱 창을 닫으면 사이드카가 정상적으로 종료되어 백엔드 프로세스가
  남지 않습니다.

## 설치 후

첫 실행은 데이터 디렉터리를 만들고, 작은 시작용 라이브러리를 채운
다음, Home 화면을 엽니다. 다음 단계는 [빠른 시작](quick-start)을
참조하세요.

설치 또는 첫 실행 중 문제가 발생하면
[문제 해결](troubleshooting)을 참조하세요.
