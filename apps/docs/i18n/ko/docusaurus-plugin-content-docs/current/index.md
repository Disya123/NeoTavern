NeoTavern은 로컬 퍼스트(local-first) AI 채팅 및 롤플레이 플랫폼입니다.
채팅, 캐릭터, 로어북, 페르소나, 설정이 모두 내 기기에 저장되며, 이를
구동할 프로바이더는 직접 선택할 수 있습니다.

## 모든 것이 내 기기에 저장됩니다

- **로컬 퍼스트 저장.** 채팅, 캐릭터, 그룹, 로어북, 메모리, 설정이
  데이터 디렉터리에 저장되며 일반 파일로 내보낼 수 있습니다.
- **오프라인 사용 가능.** 로컬 모델을 사용하면 연결 없이도 채팅을
  계속하거나, 네트워크가 끊긴 상태에서도 작업을 이어갈 수 있습니다.
- **프로바이더 자유.** 자신의 LLM, 텍스트 음성 변환(TTS), 음성 텍스트
  변환(STT), 이미지 프로바이더를 연결할 수 있습니다. API 키를 쓰거나
  아예 사용하지 않아도 됩니다.
- **플러그인 생태계.** 패널, 툴바 작업, 슬래시 명령어, 프롬프트
  인터셉터 등으로 NeoTavern을 확장할 수 있습니다. 권한 및 샌드박스
  모델이 이를 보호합니다.
- **테마.** Theme SDK의 디자인 토큰, 스킨, 레이아웃으로 앱 전체의
  모습을 다시 꾸밀 수 있습니다.
