데스크톱 앱은 NeoTavern의 네이티브 배포판입니다. Fastify 백엔드를 내장
Node.js 사이드카로 실행하는 Tauri 2 셸입니다.

## 앱 하나, 설정 없음

데스크톱 배포판은 자체 포함입니다. Node.js, SQLite, 프로덕션 웹
에셋이 패키지 안에 들어 있으므로 첫 실행에 터미널, Git, npm, 수동
데이터베이스 설정이 필요하지 않습니다. 앱을 설치하고 실행하면 로컬
API가 준비된 후 웹뷰가 열립니다.

런타임 구성 요소는 다음과 같습니다.

- **Tauri 2 셸** — 네이티브 창과 애플리케이션 라이프사이클.
- **Node.js 사이드카** — `127.0.0.1`에서 Fastify 백엔드를 로컬로
  실행하는 자체 포함 Node.js 24 바이너리.
- **SQLite** — 첫 실행 시 데이터 디렉터리에 자동으로 생성되는 로컬
  데이터베이스.

## 지원 형식

데스크톱 빌드는 대부분의 사용자가 기대하는 형식을 대상으로 합니다.

- Windows 설치 프로그램(NSIS 및 MSI).
- Windows 포터블 빌드(포터블 플래그가 있는 ZIP).
- macOS 패키지(`.app`, DMG 포함).
- Linux AppImage와 아카이브.

각 형식은 네이티브 플랫폼 러너에서 생성됩니다. 배포판이
`better-sqlite3`와 Sharp 같은 네이티브 애드온을 번들하기
때문입니다. 형식 세부 사항과 첫 실행 동작은 [패키징](packaging.md)을
참조하세요.

## 라이프사이클 보장

셸과 사이드카는 하나의 단위입니다. 창을 닫으면 백엔드가
종료됩니다. 앱은 고아 Node.js 프로세스를 절대 남기지 않습니다.
예상치 못한 백엔드 종료는 조용히 망가진 창 대신 오류로 셸을
끝냅니다. 메커니즘은 [Tauri 셸](tauri-shell.md)과 [Node
사이드카](node-sidecar.md)를 참조하세요.

## 데이터 위치

설치된 빌드는 사용자 데이터를 번들 안이 아니라 플랫폼의 앱 로컬
데이터 디렉터리에 저장합니다. 포터블 빌드가 예외입니다. 포터블
플래그가 있으면 데이터가 애플리케이션 옆의 로컬 `data/` 폴더에
있습니다. 데이터 처리 자체는 [데이터 및
저장소](../data/index.md) 섹션에서 다룹니다.
