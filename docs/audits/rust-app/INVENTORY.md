## Владение данными и зависимости

Каноническое persistent state принадлежит runtime-kernel/storage. KernelProductWire — адаптер, ChatSession — presentation state и consumer команд. Product Wire registry TypeBox — источник DTO; contracts-generated не форматировался вручную и не перегенерировался. Обнаруженные ошибки — нарушения прохождения данных или локальные повторения логики, а не доказательство необходимости смены stack.

В проверенных shared Rust путях не обнаружен live dual-write в app.db и database.sqlite. Это результат просмотра данных путей; полный packaged migration/rollback на установленном Tauri не запускался. SQL PRAGMA, migrations, backup, recovery проверяются существующими suites; их результаты нельзя переносить на неисполненные restore сценарии KR-01 или физический platform lifecycle.

Отсутствующие README у `built-in-providers`, `contracts-generated`, `neotavern-envelope`, `neotavern-host-tools`, `neotavern-package-verify`, `neotavern-tauri-local`, `provider-sdk` — документационный долг. Аудит не создаёт описания несуществующих возможностей и не меняет эти пакеты. Следующий шаг: написать README с реальными границами, публичными входами, зависимостями, feature gates и ограничениями.

## Alpha/beta и vendor patches

Workspace использует dioxus-native-dom 0.8.0-alpha.1, Blitz 0.3.0-beta.1 и stylo_taffy 0.3.0-beta.1. Точные разрешённые версии находятся в crates/Cargo.lock и cargo-metadata.json; label alpha сам по себе не дефект. Требуются pin, проверяемый upstream delta и сценарии, затронутые workaround.

Четыре локальных patch: anyrender, blitz-dom, blitz-paint, vello. Любая формулировка «только два patch» устарела. Описание workspace явно ограничивает producer seam и diagnostic hook; совпадение рендерера не означает byte-identical host behavior.

- anyrender: расширение producer seam. Принятый мост, не самостоятельная layout implementation.
- blitz-dom: защита от dead old-parent после ElementId recycling; retention/GC требуют контроля. Desktop cold reopen после arena threshold 8192 — обход проблемы lifetime, не доказательство устранения причины.
- blitz-paint: integration paint seam; необходимо сравнивать clipping/transforms и общий контракт.
- vello: диагностическое переключение shader bounds checks; default upstream unchecked. Не объявлять это новым защитным sandbox.

См. [платформенные ограничения и переоценку прошлых исправлений](PLATFORMS.md). Существующие patches не удалены: предложенные изменения должны сохранять совместимость и иметь отдельное подтверждение.

## Что не доказывает инвентаризация

Наличие тестового файла не означает проверку каждого visible action, наличия настоящего GPU либо запуска Android. Default cargo test не покрывает все feature combinations; Windows tests не дают macOS/Linux PASS. Rust codegen drift, lint/fmt failures и технические ошибки диагностического harness перечислены отдельно в протоколе, без смешивания с product regression.
