## Нативные сценарии и снимки

Fresh FakeWire probes: 1100×760,900×700,620×800,900×220; sidebar character management, header search, wheel/tick scroll, pointer actions. Для каждого сохранены snapshot PNG, swapchain PNG, DOM JSON, native log и capture metadata. Скриншоты визуально просмотрены. При компактной высоте есть overlap/clipping, но основная установленная причина взаимодействий — самостоятельная geometric hit-test модель UI-15.

Имя native-settings описывает намерение нажатия: фактический результат — Plugins. Это FAIL ожидаемого действия, а не PASS settings. native-edit также не подтвердил открытие editor; снимок остаётся read-only, поэтому edit roundtrip этим probe не засчитан. native-search открыл search field, но весь поиск по сохранённой истории этим не доказан. native-scroll подтверждает replay/render, но не весь prepend/streaming/anchor lifecycle.

Настоящий Kernel: native-live создал12messages в отдельном native-live-data. native-live-send с seed0 использовал default route без существующего chatId и получил CHAT_NOT_FOUND; исходный бинарник seed0 не выбирает сохранённый чат автоматически. Это ограничение probe invocation, а не доказательство невозможности отправки через Kernel. Корректный native-live-send-valid seeded12 в отдельном native-send-data и получил14 durable messages плюс completed generation_run. SQLite read-only проверка после завершения процесса сохранена в native-durable.json. Snapshot во время streaming может показывать Stop до durable completion: последний swapchain PNG сам по себе не удостоверяет terminal state.

React сравнивается с native-live на тех же12messages, том же database.sqlite и1100×760 через свежий headless + apps/web/dist. Оно отдельно от chat:golden:check. Результаты и ограничения — react-reference-result.json, react-reference-axe.json, react-reference.json и react-reference.png. DOM comparator проверяет limited stable slot catalogue/geometry, не весь UI. React axe не является native accessibility PASS.

chat:golden:check выполнен без capture/update эталонов: сравнение native legacy RSX ↔ Blueprint не прошло на всех4размерах (900×700:29.3981%,620×800:24.3554%,900×220:20.2561%; полный1100×760 результат в логе). Diff PNG скопированы в артефакты, goldens не перезаписаны. Причину каждого pixel difference необходимо выяснять; увеличение порога не исправляет проблему.
